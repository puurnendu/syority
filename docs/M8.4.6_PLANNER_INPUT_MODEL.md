## Planner Workflow

```
1. Select Equipment Tag  →  auto-fills: Equipment Type, System, Unit
2. Select Template        →  auto-fills: Activity list with Level Codes, phases, predecessors
3. Review Activities      →  planner can add/remove optional activities
4. Enter Quantities       →  planner enters UDF planned values (scaffolding, painting, etc.)
5. Assign Resources       →  planner selects crews from resource library
6. Review Schedule        →  CPM calculation, critical path
7. Approve Workpack       →  workflow state transition
```
