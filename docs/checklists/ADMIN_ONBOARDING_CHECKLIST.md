# Admin Onboarding Checklist

## Platform Access
- [ ] Login with tenant_administrator credentials
- [ ] Verify admin navigation sidebar

## Organization Settings
- [ ] Organization profile updated (name, logo, timezone)
- [ ] Branding configured

## User Management
- [ ] Add users with appropriate roles
- [ ] Verify role-based access (planner, engineer, viewer)
- [ ] Deactivate test users

## Site & Hierarchy
- [ ] Sites created
- [ ] Plant → Area → Unit → System hierarchy configured
- [ ] Equipment types defined

## Master Data
- [ ] Activity codes configured
- [ ] Disciplines set up
- [ ] Resource types defined
- [ ] Consumable catalog populated (if applicable)

## Templates
- [ ] Document templates uploaded
- [ ] Report templates verified
- [ ] Certificate templates configured

## Integrations
- [ ] Notification preferences set
- [ ] Email notifications tested
- [ ] AI provider configured (if licensed)

## Verification
- [ ] All users can log in
- [ ] Module access matches license
- [ ] Report generation works
- [ ] Dashboard loads correctly
- [ ] Feedback button functional
