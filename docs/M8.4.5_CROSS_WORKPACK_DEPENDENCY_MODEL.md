"Zero cross-workpack predecessor references found in 27 workpacks."

### New Evidence (P6 XER)
**[FACT]** The P6 XER contains 1,802 cross-WBS predecessor links out of 7,508 total (24%).

### Explanation
**[FACT]** Workpack PDFs only contain INTRA-workpack predecessors (WO-Op format). Cross-workpack scheduling dependencies are created in P6 by the scheduler, not by the workpack planner.

### SYORITY Implication
**[RECOMMENDATION]** SYORITY ActivityRelationship MUST support cross-workpack predecessors. The current schema already allows this (predecessor_id and successor_id are unconstrained Activity UUIDs). No schema change needed for the relationship model, but the PLANNING UI must support creating cross-workpack links.

### Cross-WP Dependency Types (from XER)

- Piping tie-in → vessel recommissioning
- Shared utility isolation → multiple equipment workpacks
- System handover milestones → unit startup
