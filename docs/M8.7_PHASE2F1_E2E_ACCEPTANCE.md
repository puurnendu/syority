# M8.7 Phase 2F.1 - E2E Acceptance

## Overview
This defines the synthetic schedule test harness requirements for M8.7 Phase 2F.

## Synthetic Schedule Generation
- The test harness initializes a brand new Organization and Event to test Tenant Isolation.
- We generate base resources: "Mechanical" (Capacity 10/day) and "Crane" (Capacity 2/day).
- Activities:
  1. **Isolation** (Critical, Duration 10h, Mech=2)
  2. **Inspection** (Float 5d, Duration 20h, Mech=5)
  3. **Bundle Pull** (Float 8d, Duration 30h, Crane=1, Mech=6)
  4. **Tube Cleaning** (Float 12d, Duration 40h, Mech=4)
  5. **Restoration** (Float 4d, Duration 20h, Mech=5)
- All predecessors point to Act 1.
- Initial demand vs capacity is designed to create resource overallocations.

## Acceptance Criteria
- Correct activities are included.
- Multi-day demand is correctly computed spanning up to 4 days (Tube Cleaning).
- Labor calculation correctly multiplies `headcount * crew_size`.
- Tenant isolation remains intact (No bleed between organizations).
