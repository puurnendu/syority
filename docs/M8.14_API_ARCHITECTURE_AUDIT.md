## API Versioning

**Current state**: No API versioning.
- All routes are `v1` implicitly
- No `/api/v1/` or `/api/v2/` prefix
- Breaking changes require frontend coordination

**Recommendation**: Add API versioning in M16 (Enterprise Integration)

## API Documentation

**Current state**: No OpenAPI/Swagger specification.
- Route contracts defined by TypeScript types
- No formal API documentation

**Recommendation**: Generate OpenAPI spec from route types in M16
