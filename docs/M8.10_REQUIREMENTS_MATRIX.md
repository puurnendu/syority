# M8.10 Enterprise Reporting Requirements Matrix

## Phase 0H — Required Dashboard Capabilities
The M8.10 EVM module requires a centralized `CostControlDashboard` distinct from the M8.8 `ScheduleControlDashboard`.

### 1. Cost S-Curve Visualizations
- **Capability:** Line chart plotting cumulative PV, EV, and AC across the Event timeline.
- **Data Source:** Time-phased array of `[date, PV, EV, AC]`.
- **Interactivity:** Overlay EAC projection line originating from the current Data Date.

### 2. Cost KPI Cards
- **BAC (Budget at Completion):** Sum of all `BaselineActivity.budgeted_cost`.
- **PV (Planned Value):** Target cost expected to be spent by Data Date.
- **EV (Earned Value):** Actual physical value earned by Data Date.
- **AC (Actual Cost):** Cumulative actuals burned.
- **CPI (Cost Performance Index):** Gauge indicator (Green > 1.0, Red < 1.0).
- **CV (Cost Variance):** Absolute dollar/hour variance.
- **EAC & ETC (Estimate at Completion/To Complete):** Financial exposure forecasting.
- **TCPI (To Complete Performance Index):** Efficiency required to hit BAC.

### 3. Drill-Down Information Architecture
The dashboard must allow financial drill-down through the WBS hierarchy:
`Event Level EVM` → `Unit Level EVM` → `System Level EVM` → `Workpack Level EVM` → `Activity Level EVM`
- **Component:** A Tree-Grid component displaying PV, EV, AC, CPI, SPI per WBS node.

### 4. Cost-Loaded Gantt
- Overlay EVM metrics (CPI/SPI) directly on the M8.8 Gantt Chart as color-coded columns or tooltip metrics.

### 5. Critical-Path Cost Exposure
- Calculate EVM specifically isolated to activities on the Critical Path (`is_critical = true`), exposing financial risk directly tied to schedule risk.
