# M8.7 Phase 2I.5 - Scenario Comparison

## Implementation Details
The `ResourceScenarioComparisonService` bridges the gap between simulated leveling recommendations and the baseline constraints, creating a `ScenarioComparisonReport`.

## Comparison Metrics
- Quantifies constraints resolved vs remaining.
- Predicts max deficit improvement based on heuristic demand shifts.
- Ensures total transparency into critical and near-critical activity displacement.
- Non-destructively exposes warnings if a scenario attempts to displace a critical activity.
