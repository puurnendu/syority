## 19. Known Limitations

1. **Password Reset**: Not implemented. Routes return 501. User model lacks token fields.
2. **Redis**: Not configured in local dev. BullMQ background jobs (CPM recalculation, report delivery) will not run.
3. **ignoreBuildErrors**: Production build bypasses TypeScript errors. Runtime crashes will occur on affected code paths.
4. **Prisma Accessor Convention**: Schema uses `@@map("snake_case")` for table names but some models are defined without `@@map`, using `snake_case` directly as model names. Code inconsistently uses camelCase or snake_case to access these models.
5. **Storage**: Defaults to local filesystem. S3 not configured.

# 🔴 NOT RELEASE READY

**Rationale**:

1. **41 Prisma accessor mismatches** will cause runtime crashes on most core business workflows (workpacks, materials, planning, joints, certificates, exports, checklists). This is a **systemic P1 issue** that blocks ~80 files across critical code paths.

2. **1,375 TypeScript errors** indicate significant code-schema drift. The build passes only because `ignoreBuildErrors: true` is set — this masks real runtime failures.

3. **Core business workflows untested**: Events, Workpacks, Activities, Materials, Safety, Reports, and Planning have NOT been verified in a running environment because the Prisma accessor mismatches make them non-functional.

4. **Tenant isolation not verified**: No multi-tenant runtime test was performed.

### Path to Release

The **single highest-priority action** is to fix the 41 Prisma accessor mismatches. This is a mechanical search-and-replace operation that would unblock runtime testing of all major workflows:

```
prisma.exportHistory     → prisma.export_history
prisma.jointMaster       → prisma.joint_masters
prisma.workpackMaterialLine → prisma.workpack_material_lines
... (41 total replacements)
```

After fixing these, re-run this QA suite to verify core workflows.
