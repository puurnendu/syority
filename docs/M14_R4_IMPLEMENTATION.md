## 2. Core Components Implemented

### 2.1 Single Source of Truth & Deep Immutability (`ReportDataset`)
- **Location:** `src/core/report-builder/ReportGenerationService.ts`
- **Contract:**
  ```ts
  export interface ReportDataset {
    reportId: string;
    reportVersion: string;
    organizationId: string;
    organization_id?: string;
    eventId: string | null;
    event_id?: string | null;
    generatedAt: string;
    generated_at?: string;
    dataAsOf: string;
    data_as_of?: string;
    generatedBy: string;
    generated_by?: string;
    reportDefinitionId?: string;
    report_definition_id?: string;
    reportDefinitionVersion?: string;
    report_definition_version?: string;
    templateId?: string | null;
    template_id?: string | null;
    templateVersion?: string;
    template_version?: string;
    filters: Record<string, any>;
    dimensions: string[];
    rows: any[];
    data: DataFetcherResult;
    aiSummary: string | null;
    provenance: ReportProvenance;
    datasetHash: string;
    dataset_hash?: string;
    hash: string;
  }
  ```
- **Deep Immutability Guarantee:**
  A recursive freezing utility `deepFreeze(obj)` freezes the dataset, its nested `data` object, `rows` array, `provenance` metadata, `filters`, and `dimensions`. Any attempt to mutate properties on the dataset or its nested arrays throws a `TypeError: Cannot assign to read only property`.
- **Deterministic Hashing:**
  Calculated via SHA-256 over canonicalized JSON representation of:
  - `reportId`
  - `reportVersion`
  - `organizationId`
  - `eventId`
  - `dataAsOf`
  - `filters` (deterministically sorted keys)
  - `rows` / `data`
  - `authoritySources`
  **Nondeterministic runtime attributes** (`generatedAt`, execution UUIDs) are strictly excluded from the hash payload.

### 2.2 Governed PDF Renderer
- **Engine:** Headless Puppeteer browser singleton (`@/lib/puppeteer`).
- **Features:**
  - Standard A4 / Letter page sizing with configurable margins.
  - Page orientation support (portrait or landscape).
  - Print styling with CSS `@media print`, `-webkit-print-color-adjust: exact`, and `.page-break` boundaries.
  - Injected headers and footers with dynamic page numbers (`Page {{page}} of {{total_pages}}`).
  - Styled KPI cards, tables with alternating row stripes, and chart image/SVG blocks without recalculating any metrics.
  - Storage of generated binary PDF buffer directly into `report_artifacts.file_data`.

### 2.3 Governed XLSX Export
- **Engine:** `ExcelJS.Workbook`.
- **Features:**
  - **Sheet 1 (`Report Data` / Section Sheets):**
    - High-contrast styled headers with tenant branding primary color and bold white typography.
    - Preserved data types (numbers, dates, text) and values.
    - Percentages and financial metrics preserved exactly as supplied by upstream authorities with zero recalculation.
    - Auto-fitted column widths with cell borders.
  - **Sheet 2 (`Metadata & Provenance`):**
    - Audit log documenting: Report Name, Definition Slug, Version, Organization ID, Event ID, Generated At, Data As Of, Generated By, Filters Applied, Authority Sources, Dataset SHA-256 Hash, and Immutability Certification.
  - Storage of generated XLSX buffer into `report_artifacts.file_data`.

### 2.4 Governed CSV Export
- **Engine:** Deterministic RFC 4180 serializer.
- **Features:**
  - Deterministic column ordering based on dataset row properties.
  - Full RFC 4180 quotation handling for strings containing commas, quotes (`"` escaped as `""`), and newlines.
  - UTF-8 with Byte Order Mark (`\uFEFF`) to guarantee flawless opening in international Microsoft Excel installations.
  - Zero calculation or metric transformation.

### 2.5 Presentation Configuration (Client Branding & Layout)
- **Engine:** `ReportLayoutService.resolveBranding` + `BrandingService.resolve`.
- **Scope:**
  - Client logo (`logo_url`), dimensions, and alignment.
  - Primary, secondary, and accent colors.
  - Header and footer HTML templates with variable interpolation (`{{orgName}}`, `{{date}}`, `{{datetime}}`, `{{report}}`).
  - Signature and approval blocks (`show_signature`, `signature_labels`).
  - Confidentiality markings and disclaimer text.
  - Page size, orientation, and margins.
- **Authority Constraint:** Client branding modifies PRESENTATION ONLY. Authoritative metrics (Progress %, EVM, Float, Readiness, Exceptions) are NEVER altered.

### 2.6 Report Scheduling & Delivery
- **Engine:** `ReportScheduleService` + `prisma.notification_queue` / BullMQ `reportDeliveryWorker`.
- **Features:**
  - Frequency configurations: `daily`, `weekly`, `monthly`, `hourly`, `manual`.
  - Next-run calculation (`computeNextRun`) without user exposure to raw cron syntax.
  - Strict tenant and event isolation: all operations (`create`, `getById`, `update`, `delete`, `trigger`) verify `organization_id` and `event_id`.
  - Trigger execution delegates 100% to the manual `ReportGenerationService.generate()` pipeline.
  - Delivery dispatch:
    - Email: creates pending delivery tasks in `prisma.notification_queue`.
    - In-App: creates notifications in `notifications` table or generation history.
  - Error isolation: delivery failures update `last_error` and generation error logs without corrupting the generated report dataset or stored artifact.

### 2.7 Historical Snapshots & Security Hardening
- **Snapshot Preservation:**
  - Every generation creates an immutable audit row in `report_generations` with `dataset_hash`, `filters_applied`, `parameters`, `record_count`, `file_size_bytes`, `duration_ms`, `started_at`, `completed_at`, `status`, and linked `report_artifacts`.
- **Tenant Isolation Enforcement:**
  - `ArtifactService.getForDownload(id, organizationId)` rejects cross-tenant downloads.
  - `ArtifactService.archive(id, organizationId)` rejects cross-tenant archiving.
  - `generations/[id]` API enforces `generation.organization_id === session.user.organization_id`.
  - `schedules/[id]` and `schedules/[id]/trigger` APIs enforce schedule ownership.
