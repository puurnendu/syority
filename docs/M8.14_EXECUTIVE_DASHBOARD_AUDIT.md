## Current Executive View

The current `/dashboard` page shows:
1. **PortfolioDashboard** component (client-side)
   - Summary stat cards (workpacks, progress, overdue, constraints, certs, lessons, safety, systems, materials, joints, blinds)
   - S-curve chart
   - System progress grid

2. **Summary Cards** (server-side)
