## Progress Data Sources Per Dashboard

| Dashboard | Progress Source | SPI Source | Authoritative? |
|-----------|---------------|-----------|----------------|
| **Portfolio Dashboard** | `GET /api/dashboard/portfolio-stats` → `ProgressAggregationService` | `EvmCalculationService` with fallback | ✅ Yes |
| **TA Dashboard — Overview** | S-curve from `SchedulingService` | Inline SPI display | ✅ Uses authoritative KPIs |
| **TA Dashboard — Progress Intelligence** | `GET /api/events/[eventId]/progress?all=1&identical=1` | `SpiAdapter` | ✅ Yes |
| **Execution Cockpit** | `FieldExecutionService.getExecutionSummary()` → `overall_progress` cache | N/A | ✅ Cache synced by authoritative |
| **EVM Dashboard** | `EvmCalculationService` (protected M8.10) | `EvmCalculationService` | ✅ Yes (EVM authority) |
| **Schedule Dashboard** | `ScheduleHealthService` (protected M8.8) | Duration-weighted SPI | ✅ Yes (schedule health authority) |

## Common KPI Definitions

| KPI | Definition | Authority |
|-----|-----------|-----------|
| Overall Progress % | Duration-weighted execution progress | `ProgressCalculationService` |
| Completed Equivalent Hours | Σ(duration × progress% / 100) | `ProgressCalculationService` |
| Balance Hours | Total Duration − Completed Equivalent | `ProgressCalculationService` |
| SPI (EVM) | BCWP / BCWS | `EvmCalculationService` |
| CPI | BCWP / ACWP | `EvmCalculationService` |
| SPI (Execution) | Actual weighted progress / time-proportional planned | `SpiAdapter` |
| Activity Completion Rate | Completed activities / Total activities × 100 | `ProgressCalculationService` |

## Common Dashboard Context Contract

Every dashboard MUST receive and filter by the same context:

```typescript
interface DashboardContext {
  organizationId: string;   // Tenant isolation
  eventId?: string;         // Turnaround event (required for TA Dashboard)
  siteId?: string;          // Site filter
  // Optional filters:
  unitId?: string;
  disciplineId?: string;
  contractorId?: string;
  workpackId?: string;
  equipmentTypeId?: string;
  reportingDate?: Date;     // Defaults to now
}
```

### Consistency Rules
1. Two dashboards viewing the same event MUST show the same progress numbers
2. Dimensional filters MUST produce consistent subsets
3. Reporting date MUST default to `now` unless explicitly overridden
4. Cancelled/deleted activities MUST be consistently excluded
