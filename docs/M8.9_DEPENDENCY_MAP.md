# M8.9 DEPENDENCY MAP

**Date:** 2026-08-31
**Status:** DRAFT (Awaiting Specifications)

This map defines the protected boundaries and integration points that M8.9 must adhere to, based on the established M8.7 and M8.8 platforms.

## Core Engines (PROTECTED)
*Modifications strictly prohibited without extreme justification.*
- `src/lib/scheduleEngine.ts` (CPM, Logic, Float)
- `ResourceConstraintService` (Resource Availability, Loading)

## M8.8 Schedule Control Services (REUSABLE)
*To be reused and extended, not duplicated.*
- `ScheduleBaselineService`
- `ScheduleVarianceService`
- `ScheduleForecastService`
- `ScheduleHealthService`
- `CriticalPathIntelligenceService`
- `ScheduleChangeControlService`

## UI & Presentation Layer
- `app/(dashboard)/planner-workspace/page.tsx`: The primary integration shell. M8.9 features must plug into the `activeView` model.
- `src/stores/useWorkspaceStore.ts`: Global state for the Planner Workspace.

## Security & Architecture
- **API Guard:** `guardApi('nav.schedule')` (or equivalent valid permission) MUST wrap all new endpoints.
- **Tenant Guard:** `withTenantGuard` MUST be used. Cross-tenant access is strictly forbidden.
- **Database Rules:** No raw SQL allowed for analytical queries without parameterization and explicit tenant scoping.
