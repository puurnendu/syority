# M8.4 — Workpack Lifecycle State Machine & Execution Gates

This document defines the deterministic state transitions, allowed actions, role constraints, and QA/QC gates governing the Workpack lifecycle in SYORITY.

---

## 1. Workpack Lifecycle State Machine

```
              ┌─────────┐
              │  DRAFT  │
              └────┬────┘
                   │ submit
                   ▼
            ┌──────────────┐
            │ UNDER_REVIEW │
            └──────┬───────┘
                   │ approve (reject -> DRAFT)
                   ▼
              ┌──────────┐
              │ APPROVED │
              └────┬─────┘
                   │ issue to field
                   ▼
               ┌────────┐
               │ ISSUED │ ◄── [ Execution Workspace Active ]
               └───┬────┘     • Start Activities
                   │          • Log Actual Progress (0-100%)
                   │          • Raise/Clear QA Hold Points
                   │          • Resolve Punch Items
                   │
                   ▼ [ Mandatory Hold-Point Gate Verification ]
             Are all Hold Points Cleared?
            ├── NO  ──► Block Completion (422 Unprocessable Entity)
            └── YES ──► Allow Completion
                   │
                   ▼ close
              ┌────────┐
              │ CLOSED │
              └────────┘
```

---

## 2. Transition Rules & Preconditions

| Transition | Allowed Previous States | Target State | Preconditions & Execution Gate |
|---|---|---|---|
| **Submit for Review** | `draft` | `under_review` | Workpack must have title and at least 1 activity |
| **Approve** | `under_review` | `approved` | Planner / Supervisor role required |
| **Reject / Request Changes** | `under_review` | `draft` | Rejection comment required |
| **Issue to Field** | `approved` | `issued` | Ready for field execution |
| **Complete & Close** | `issued` | `closed` | **Mandatory QA Gate:** All activities with `hold_point_type != null` must have corresponding `qa_clearance_records`. If unresolved hold points exist, completion is **BLOCKED**. |
| **Cancel** | `draft`, `under_review`, `approved` | `cancelled` | Cannot cancel workpack in active field execution without formal waiver |
