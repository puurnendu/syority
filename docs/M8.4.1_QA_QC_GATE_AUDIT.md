# M8.4.1 — QA/QC Hold-Point Gate Audit

Audit of the QA/QC inspection gate preventing premature workpack completion and closure.

---

## 1. Gate Architecture & Enforcement Logic

Enforced in `src/modules/Workpack/Services/WorkflowService.ts` during `WorkflowService.close()`:

```typescript
// GATE 3: Unresolved QA hold points block closure
const activitiesWithHoldPoints = await prisma.activity.findMany({
    where: {
        workpack_id: workpackId,
        organization_id: organizationId,
        hold_point_type: { not: null },
        deleted_at: null,
    },
    select: { id: true, activity_number: true, description: true },
});

if (activitiesWithHoldPoints.length > 0) {
    const actIds = activitiesWithHoldPoints.map((a) => a.id);
    const clearedRecords = await prisma.qa_clearance_records.findMany({
        where: {
            workpack_id: workpackId,
            organization_id: organizationId,
            activity_id: { in: actIds },
        },
        select: { activity_id: true },
    });
    const clearedSet = new Set(clearedRecords.map((c) => c.activity_id));
    const uncleared = activitiesWithHoldPoints.filter((a) => !clearedSet.has(a.id));
    if (uncleared.length > 0) {
        throw new WorkflowError(
            `${uncleared.length} mandatory QA hold point(s) remain uncleared (e.g. ${uncleared[0].activity_number || uncleared[0].description}). All hold points must be cleared before closure.`
        );
    }
}
```
