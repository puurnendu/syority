# M8.5 — Schedule Baseline vs. Actual Execution Integrity Proof

This document provides formal verification and mathematical proof that recording field execution actuals does **NOT** alter the planning schedule baseline or mutate CPM float calculations.

## 3. Invariant Guarantee

Field operations capture reality. Planning baselines evaluate variances against reality. CPM recalculation occurs **only** when an authorized planner explicitly invokes `/api/schedule/calculate`.
