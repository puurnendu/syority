# M8.7 Phase 2C — Implementation Plan (Execution Control)

## 1. Schema Upgrades
- **Permit Model**: Upgrade the `Permit` model to include `organization_id` (UUID, mandatory) and `site_id` (UUID, mandatory).
- **Constraint Unification**: Standardize execution blockers on the `ConstraintLog` model (since it's already used by `REPORT_DELAY` and `WorkflowService`). Map constraints strictly to the execution gates.

## 2. The Execution Control Contract
Create a strict Execution Control validation sequence in `FieldExecutionService.executeActivityAction`. Before an Activity can be `START`ed, the backend will verify:
1. **Workpack State**: Must be `issued` or `in_execution`. (Already exists).
2. **Constraints**: Workpack must not have any `ConstraintLog` items with severity = `critical` and status = `open`.
3. **Permits**: If the Activity requires a permit (based on activity properties or workpack requirements), a valid, issued `Permit` must exist for the shift.
4. **Prerequisites**: If the Activity has dependencies (e.g., predecessor activities in the CPM network), they must be marked as `completed`.

## 3. Service Layer Enhancements
- **PermitService**: Create a new `PermitService` to manage Permit issuance, validation, and expiration.
- **ExecutionValidationEngine**: Refactor the gate checks in `FieldExecutionService` into a cohesive `verifyExecutionPrerequisites(activityId, orgId)` method that returns boolean or throws specific blockage errors.

## 4. Field Cockpit Integrations
- Integrate `Permit` status visualization into the `getExecutionBoard` API.
- Surface blockage reasons (Missing Permit, Open Constraint, Predecessor incomplete) directly in the `LookaheadItemDTO` so the UI can disable the "Start" button and explain why.

## Execution Phasing
1. **Phase 2C.1**: Prisma Schema migrations (Permit multi-tenancy) and PermitService creation.
2. **Phase 2C.2**: Execution Control Gate implementation in `FieldExecutionService`.
3. **Phase 2C.3**: API and UI alignment to surface the new execution blockers in the Cockpit.
