# M8.0 — Syority Product Gap Analysis

This document evaluates the frozen M7.9.4 technical baseline against the operational requirements of an industrial Shutdown / Turnaround Management System (SYORITY) for refineries, petrochemical plants, fertilizer plants, chemical complexes, and power generation facilities.

---

## 1. Product Capability Classification

| Classification | Definition |
|---|---|
| **A. REQUIRED FOR CORE PRODUCT** | Mission-critical for planning, scheduling, executing, and closing an industrial turnaround. |
| **B. USEFUL BUT OPTIONAL** | High-value operational features that enhance turnaround efficiency but are not day-1 blockers. |
| **C. ENTERPRISE PLATFORM** | Multi-tenant SaaS, licensing, tenant-provisioning, and cluster management features. |
| **D. LEGACY / UNNECESSARY** | Over-engineered or non-shutdown workflows that can be parked or hidden. |
| **E. MISSING** | Unimplemented capabilities required by turnaround managers, planners, and contractors. |

## 3. Detailed Module-by-Module Gap Analysis

### 3.1 Organization, Site & Hierarchy
*   **Current State:** 100% Implemented and validated in M7.9.2/M7.9.3.
*   **Operational Readiness:** Ready for production.
*   **Gap:** First-time setup currently uses developer seeds or platform tenant provisioning.
*   **Action:** Provide a clean, 3-minute initial Setup Wizard asking only for: Company Name, Site Name, and Admin Password.

### 3.2 Shutdown Management (Events)
*   **Current State:** Fully implemented. Supports start/end dates, milestone tracking, budget manhours, cost tracking, and parent/child multi-event campaigns.
*   **Gap:** UI lacks a persistent "Current Active Shutdown" global selector. When navigating between Workpacks, Schedule, and QA/QC, the system should remember the active shutdown context.
*   **Action:** Add top-bar Shutdown Selector dropdown that stores `active_event_id` in session storage or cookie.

### 3.3 Planning & WBS
*   **Current State:** Activities support WBS codes, disciplines, contractor assignments, planned durations, early/late dates, and resource requirements.
*   **Gap:** Planners currently have to open individual dialogs to edit activities.
*   **Action:** Implement an interactive tabular grid (like Excel or SmartSheet) with keyboard navigation for rapid activity entry during turnaround planning freezes.

### 3.4 Scheduling & Critical Path
*   **Current State:** Predecessor/successor dependencies and total float fields exist in the database.
*   **Gap:** The Gantt chart view is currently read-only.
*   **Action:** Add interactive Gantt chart logic with client-side Critical Path Method (CPM) calculation to immediately visualize the zero-float driving path.

### 3.5 Workpack Assembly & ID Generation
*   **Current State:** 100% operational with verified atomic sequential numbering (`U10-MEC-001`, `U10-MEC-002`, `GEN-GEN-001`), line lists, joint integrity records, auto-attached certificate templates, and PDF generation.
*   **Gap:** Minor UI polish for downloading merged multi-document PDF workpack binders in bulk.
*   **Action:** Provide a 1-click "Download Complete Workpack Binder (PDF)" button.

### 3.6 Execution & Field Progress Tracking
*   **Current State:** Shift report generation, progress logging, constraint logging, and punch lists are implemented.
*   **Gap:** Mobile field usability. Field execution engineers need a lightweight, high-contrast, touch-friendly screen on phones or tablets to log actual activity percentages and field notes.
*   **Action:** Create a responsive `/field` execution view optimized for mobile browsers.

### 3.7 QA/QC & Flange Joint Integrity
*   **Current State:** Mature and highly specialized. Supports gasket/bolt spec matrices, torque tightening values, clearance milestones, box-up sign-offs, and hold points.
*   **Gap:** None. This is one of the strongest features in the application.

### 3.8 Safety (HSE) Tracking
*   **Current State:** Daily safety manhours, PTW permits issued, toolbox talk tallies, and Near Miss incident logs fully functional.
*   **Gap:** None. Ready for production.

### 3.9 Reporting & Dashboards
*   **Current State:** 24h and 72h lookahead queries, real-time KPI stats, and printable summaries operational.
*   **Gap:** Automated daily 06:00 AM email dispatch of the Shutdown Daily Progress Report (PDF).
*   **Action:** Configure scheduled local job or 1-click printable PDF handover sheet.
