## 3. Grid Capabilities & Planner Experience

*   **Keyboard Navigation:**
    *   `Enter`: Commits cell and navigates to the row below.
    *   `Tab` / `Shift+Tab`: Commits cell and moves right / left.
    *   `Arrows`: Moves active focus between spreadsheet cells.
    *   `Double-Click / Space / F2`: Enters inline edit mode.
    *   `Escape`: Reverts cell value and cancels edit mode.
*   **Excel Clipboard TSV Paste:** Planners can copy thousands of rows from Microsoft Excel, LibreOffice, or Google Sheets and paste them directly. The system automatically extracts `Activity #`, `Description`, `WBS`, `Discipline`, `Duration`, `Start`, `End`, and `Contractor` with line-by-line syntax validation before committing.
*   **Automatic Date & Duration Calculations:** Modifying duration automatically recalculates planned finish date; modifying start/finish recalculates planned duration.
*   **Frozen Headers & Columns:** `Activity #` and `Activity Description` stay pinned to the left during horizontal scrolling.
*   **Active Shutdown Context Awareness:** Header dynamically renders the current turnaround banner (`ABC Refinery | TA-2026 | Oct 01 → Oct 31, 2026 | Count | Unsaved`).
