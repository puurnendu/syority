## Key Design Decisions
1. **[FACT]** Activity Family is SEPARATE from Execution Phase — an activity like ISO.BLINDING is in Family=ISO but Phase can be SHUTDOWN.
2. **[FACT]** Canonical codes are equipment-independent: REPAIR.WELDING applies to HX, VES, PIPE, COL.
3. **[FACT]** Native source codes (Ex.RTub, PIP.Wel) are retained only as mappings, not user-facing identity.
4. **[RECOMMENDATION]** Each activity carries conditionality (MANDATORY/OPTIONAL/CONDITIONAL) with a plain-text condition expression.
