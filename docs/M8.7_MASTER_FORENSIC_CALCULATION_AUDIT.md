### Demand Distribution Logic

```
durationDays = Math.ceil(duration_hours / hoursPerDay)
for each day from planned_start to planned_start + durationDays:
    daily_demand += headcount * crew_size (for labor)
    daily_demand += quantity (for machine/material)
```

**P1-002**: Uses `duration_hours / hoursPerDay` for day count instead of actual `planned_start` → `planned_end` range. If an activity has a non-standard calendar (e.g., planned_end - planned_start ≠ duration_hours / hoursPerDay), the demand spread will be incorrect.
