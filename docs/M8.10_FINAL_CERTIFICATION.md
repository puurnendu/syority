## 3. EVM Formulas

All formulas match `M8.10_ARCHITECTURE_LOCK.md §3` exactly:

| Metric | Formula | Zero-Division | Tests |
|--------|---------|:---:|:---:|
| BAC | SUM(BaselineActivity.budgeted_cost) | — | ✅ |
| PV | BAC × planned_pct(T) | PV=0 if no BAC | ✅ |
| EV | BAC × min(progress/100, 1.0) | EV=0 if no BAC | ✅ |
| AC | Activity.actual_cost | AC=0 if null | ✅ |
| CV | EV − AC | — | ✅ |
| SV | EV − PV | — | ✅ |
| CPI | EV / AC | AC=0,EV=0→1.0; AC=0,EV>0→null | ✅ |
| SPI | EV / PV | PV=0,EV=0→1.0; PV=0,EV>0→null | ✅ |
| EAC | AC + (BAC−EV)/CPI | CPI=null/0→null | ✅ |
| ETC | EAC − AC | EAC=null→null | ✅ |
| VAC | BAC − EAC | EAC=null→null | ✅ |
| TCPI | (BAC−EV)/(BAC−AC) | BAC=AC→null | ✅ |
