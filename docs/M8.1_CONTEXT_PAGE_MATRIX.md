# M8.1 — Context Page Matrix

This matrix classifies all major application pages and defines how they interact with the **Active Shutdown Context (`active_event_id`)**.

---

## 1. Page Scoping Classification

| Page Route | Classification | Reacts to Active Shutdown? | Expected Behavior with Active Shutdown Context |
|---|---|---|---|
| `/dashboard` | **Shutdown Scoped** | **YES** | Displays real-time KPIs, S-Curve, Critical Path, and lookaheads for the active shutdown. |
| `/events` (or `/shutdowns`) | **Shutdown Hub** | **Context Switcher** | Lists all shutdowns with status tags; allows setting/switching active shutdown. |
| `/events/[eventId]` | **Shutdown Workspace** | **Explicit Context** | Dedicated workspace hub for the specified shutdown. |
| `/events/[eventId]/scope` | **Shutdown Scoped** | **Explicit Context** | Scope register and freeze items for the shutdown. |
| `/events/[eventId]/wbs` | **Shutdown Scoped** | **Explicit Context** | WBS hierarchy and work breakdown for the shutdown. |
| `/events/[eventId]/safety` | **Shutdown Scoped** | **Explicit Context** | HSE manhours and incident logs for the shutdown. |
| `/planning/templates` | **Site Master Data** | **NO** | Reusable shutdown standard templates; shared across all campaigns. |
| `/planning/systems` | **Site Hierarchy** | **NO** | Persistent system breakdown under physical plant units. |
| `/planning/units` | **Site Hierarchy** | **NO** | Persistent process units belonging to the physical site. |
| `/planning/joints` | **Shutdown Scoped** | **YES** | Flange joint make/break and torque tracking for the active turnaround. |
| `/planning/blinds` | **Shutdown Scoped** | **YES** | Positive isolation blind list installed/removed for the active turnaround. |
| `/schedule` | **Shutdown Scoped** | **YES** | Gantt chart and CPM activities filtered by active shutdown. |
| `/workpacks` | **Shutdown Scoped** | **YES** | Workpack register and assemblies filtered by active shutdown. |
| `/workpacks/[id]` | **Workpack Detail** | **Inherited Context** | Inherits `event_id` from the parent workpack record. |
| `/safety` | **Shutdown Scoped** | **YES** | Defaults to active shutdown HSE metrics; offers all-events view toggle. |
| `/permits` | **Shutdown Scoped** | **YES** | Permits to Work (PTW) issued for the active turnaround. |
| `/asset-register` | **Site Master Data** | **NO** | Permanent equipment tags (`P-1001`, `E-102`) belonging to the physical site. |
| `/settings/hierarchy/*` | **Site Master Data** | **NO** | Physical Site → Plant → Area → Unit → System configuration. |
| `/settings/organization`| **Company Master** | **NO** | Company profile and tenant configuration. |
| `/platform/*` | **Platform Admin** | **NO** | Multi-tenant platform management and host telemetry. |

---

## 2. Context Propagation Rules

1.  **Direct Route Overrides:** If a URL explicitly contains an `[eventId]` (e.g. `/events/45830d69.../scope`), the page scopes to that specific event regardless of the stored global cookie.
2.  **Implicit Route Scoping:** When accessing top-level routes (e.g. `/dashboard`, `/schedule`, `/workpacks`), the page reads the active shutdown from `useActiveShutdown()` or the `active_event_id` cookie.
3.  **Empty State Fallback:** If no shutdown has been created yet or no shutdown is selected, the page displays a clear prompt with a button: *"Create or Select a Shutdown to view schedule and workpacks"*.
