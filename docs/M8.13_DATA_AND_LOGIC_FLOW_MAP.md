## Data Freshness Map

| KPI | Current Freshness | Target Freshness | Method |
|-----|------------------|-----------------|--------|
| Execution Progress | Near real-time (on page load) | Near real-time | Live query |
| Schedule (CPM) | On-demand recalculation | After progress/date change | Event-driven |
| EVM (PV/EV/AC) | Manual snapshot | Auto-snapshot daily + on progress change | Scheduled + event |
| Material Readiness | Live query | Live query | No change |
| Safety | Live query | Live query | No change |
| Scope Change Impact | On scope change submission | On scope change submission | No change |
| Forecast | On-demand calculation | After progress change | Event-driven |
| Identical Activity | Not implemented | Live query with caching | Computed with TTL |
| Executive KPIs | Not implemented | Near real-time with 60s cache | Redis/in-memory cache |
