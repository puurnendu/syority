# M8.10 Phased Implementation Plan

## Overview
Based on the Phase 0 Discovery, the database lacks the foundational cost structures and seed data required to instantly turn on EVM. The implementation must be phased.

## Phase 1: Foundation & Data Structures
1. **Schema Updates:** 
   - Add `budgeted_cost` to `Workpack` (roll-up caching).
   - Add `standard_rate` to `Resource`.
   - Add `CostSnapshot` table for time-phased S-Curve persistence.
2. **Data Seeding:** 
   - Build a script to retroactively cost-load the existing 37 activities in `syority` tenant to establish a valid BAC.
3. **Core Services:**
   - Implement `EvmCalculationService.ts` containing the core PV, EV, AC, CPI, EAC formulas.

## Phase 2: Engine Integration
1. **Baseline Hooks:** 
   - Hook into `ScheduleBaseline` creation to automatically generate the time-phased PV curve.
2. **Progress Hooks:** 
   - Hook into `ProgressLog` submission to trigger real-time EV generation and AC accumulation.
3. **M8.9 Scenario Hooks:** 
   - Integrate `EvmCalculationService` into the scenario simulation engine to project What-If EVM.

## Phase 3: Presentation Layer
1. **API Endpoints:**
   - Create `GET /api/events/[eventId]/evm/summary`
   - Create `GET /api/events/[eventId]/evm/s-curve`
2. **Dashboard UI:**
   - Build `CostControlDashboard.tsx` utilizing Recharts for S-Curves.
   - Build WBS Tree-Grid component for drill-down EVM performance.

*Note: This is a proposed architectural plan. No implementation will commence until Phase 1 is formally authorized.*
