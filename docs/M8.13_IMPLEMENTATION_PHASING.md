# M8.13 Implementation Phasing

## Recommended Phases

### Phase 1: Foundation (Schema + Core Service)

**Deliverables:**
1. `StandardActivityType` Prisma model + migration
2. `Activity.standard_activity_type_id` new field + migration
3. `Asset.equipment_type_id` new field + migration
4. `src/core/progress/ProgressCalculationService.ts` — pure math, no I/O
5. `src/core/progress/ProgressAggregationService.ts` — DB queries
6. `src/core/progress/types.ts` — shared types
7. Seed data: Standard activity types for common equipment types
8. API: `/api/events/[eventId]/progress` — event-level progress
9. API: `/api/events/[eventId]/progress/recalculate` — force sync

**Exit Criteria:**
- ProgressCalculationService produces same results as FieldExecutionService.calculateWeightedProgress()
- API returns correct duration-weighted progress for seed data
- Zero protected files modified
- All new APIs use withTenantGuard + guardApi

**Estimated Effort:** 3-4 days

---

### Phase 2: Dimensions + Consumer Redirect

**Deliverables:**
1. API: `/api/events/[eventId]/progress/disciplines`
2. API: `/api/events/[eventId]/progress/contractors`
3. API: `/api/events/[eventId]/progress/units`
4. Auto-sync trigger: Activity progress change → Workpack.overall_progress
5. Redirect `portfolio-stats` SPI/CPI to use EvmSnapshotService
6. Redirect `portfolio-stats` avg_progress to use ProgressAggregationService
7. Redirect report providers to use ProgressAggregationService

**Exit Criteria:**
- All dashboards show consistent progress numbers
- Workpack.overall_progress auto-syncs within 1s of activity progress change
- Inline SPI/CPI calculation eliminated from portfolio-stats
- Report providers use common service

**Estimated Effort:** 3-4 days

---

## Migration Safety

All migrations are additive:
- Phase 1: ADD tables, ADD columns (all nullable or with defaults)
- Phase 2: No schema changes
- Phase 3: No schema changes (classification done in application layer)
- Phase 4: No schema changes

**Zero destructive changes. Zero column drops. Zero renames.**
