# M8.13 Architecture Recommendation

## Proposed Architecture

### New Services (M8.13 — `src/core/progress/`)

```
src/core/progress/
├── ProgressCalculationService.ts    — Pure, deterministic progress math
├── ProgressAggregationService.ts    — Database queries + aggregation
├── IdenticalActivityService.ts      — Standard activity type analysis
├── ExecutiveKPIService.ts           — Cross-functional KPI assembly
└── types.ts                         — Shared types
```

### Service Architecture

```
┌────────────────────────────────────────────────┐
│          ProgressCalculationService             │
│  (PURE — no I/O, no HTTP, no persistence)       │
│                                                 │
│  calculateWeightedProgress(activities)           │
│  calculatePlannedProgress(activities, dataDate)  │
│  calculateBalanceWork(activities)                │
│  calculateDimensionProgress(activities, groupBy) │
│                                                 │
│  Input: { progress_percent, duration_hours }[]   │
│  Output: { weighted_progress, dimensions }       │
└─────────────────────┬──────────────────────────┘
                      ↓ used by
┌────────────────────────────────────────────────┐
│         ProgressAggregationService              │
│  (I/O layer — Prisma queries)                   │
│                                                 │
│  getEventProgress(orgId, eventId)                │
│  getWorkpackProgress(orgId, workpackId)           │
│  getDisciplineProgress(orgId, eventId)            │
│  getContractorProgress(orgId, eventId)            │
│  getUnitProgress(orgId, eventId)                  │
│  getEquipmentTypeProgress(orgId, eventId)         │
│  syncWorkpackProgress(orgId, workpackId)          │
│                                                 │
│  Uses: SQL aggregation for performance            │
│  Fallback: Prisma queries                        │
└─────────────────────┬──────────────────────────┘
                      ↓ used by
┌────────────────────────────────────────────────┐
│         IdenticalActivityService                │
│  (Equipment type → Standard activity analysis)   │
│                                                 │
│  getIdenticalActivityMatrix(orgId, eventId)      │
│  getEquipmentCompletion(orgId, eventId, eqType)  │
│                                                 │
│  Requires: StandardActivityType model            │
│  Requires: Activity.standard_activity_type_id    │
└─────────────────────┬──────────────────────────┘
                      ↓ used by
┌────────────────────────────────────────────────┐
│          ExecutiveKPIService                    │
│  (Cross-functional aggregation)                 │
│                                                 │
│  getExecutiveKPIs(orgId, eventId)                │
│                                                 │
│  Combines:                                      │
│    Progress → from ProgressAggregation           │
│    Schedule → from ScheduleHealthService         │
│    Cost/EVM → from EvmSnapshotService            │
│    Safety → from prisma.safetyLog                │
│    Materials → from MaterialConstraintService    │
│    Scope → from ScopeChange tables               │
│    Risk → derived critical path + constraints    │
│                                                 │
│  Output: ExecutiveKPIPayload                     │
└────────────────────────────────────────────────┘
```

### Schema Additions

```prisma
/// Standard Activity Type — canonical activities per equipment type
model StandardActivityType {
  id                  String        @id @default(uuid()) @db.Uuid
  organization_id     String?       @db.Uuid
  equipment_type_id   String        @db.Uuid
  name                String
  code                String
  description         String?
  is_mandatory        Boolean       @default(true)
  typical_duration_hrs Float?
  sort_order          Int           @default(0)
  is_active           Boolean       @default(true)
  created_at          DateTime      @default(now())
  updated_at          DateTime      @updatedAt
  
  equipment_type      EquipmentType @relation(fields: [equipment_type_id], references: [id])
  
  @@unique([equipment_type_id, code])
  @@index([organization_id, equipment_type_id])
  @@map("standard_activity_types")
}
```

**Activity additions (new field):**
```
standard_activity_type_id  String?  @db.Uuid
```

**Asset additions (new field):**
```
equipment_type_id  String?  @db.Uuid
```
