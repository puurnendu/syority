## KPI Data Source Registry

### 1. Progress %

| Element | Source of Truth | Calculation Service | API | Dashboard Consumer | Cache | Duplicates |
|---------|----------------|--------------------|----|-------------------|-------|-----------|
| Activity Progress | `Activity.progress_percent` | `ProgressCalculationService` | `/api/events/[id]/progress` | TA Dashboard, Execution Cockpit | `Workpack.overall_progress` | ❌ None (M8.13 certified) |
| Workpack Progress | `Σ(dur × prog%) / Σ(dur)` | `ProgressCalculationService` | `/api/events/[id]/progress` | TA Dashboard, Portfolio | `Workpack.overall_progress` | ❌ None |
| Event Progress | `Σ(all activities dur × prog%) / Σ(dur)` | `ProgressAggregationService` | `/api/events/[id]/progress` | TA Dashboard, Portfolio Stats | None | ❌ None |
| Portfolio Progress | `ProgressAggregationService.getDashboardSummary()` | Authoritative | `/api/dashboard/portfolio-stats` | Portfolio Dashboard | None | ❌ None |

**M8.13 Verification**: ✅ All progress flows through authoritative `ProgressCalculationService`
