### Key Reports

| Report | Dimensions Used | Example |
|---|---|---|
| Equipment Progress | Equipment Tag × Level Code × Quantity | E-205: Welding 67%, NDT 74% |
| Phase Progress | Phase × Activity Count/Duration | IR: 72%, CP: 15% |
| Level Code Progress | Canonical Level Code × Plan/Actual | REPAIR.WELDING: 840/1250 = 67% |
| QA Dashboard | Hold Point AI/TS × Cleared/Pending | AI First: 45/60, TS Final: 12/18 |
| Contractor Progress | Contractor × Activities × Duration | HPCL: 85%, L&T: 72% |
| Discipline Progress | Discipline × Phase | Mechanical IR: 68% |

### QA in Reporting
**[RECOMMENDATION]** Track QA separately from physical progress:
- Physical Progress: Duration-weighted across non-QA activities
- QA Progress: Count-based (Hold Points cleared / total)
- Combined: Weighted blend for overall status
