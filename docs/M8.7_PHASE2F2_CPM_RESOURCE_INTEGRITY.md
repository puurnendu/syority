# M8.7 Phase 2F.2 - CPM & Resource Integrity

## Overview
This phase verifies that CPM calculations and Resource computations maintain perfect integrity before, during, and after Resource Leveling.

## Key Invariants
- **Critical & Zero-Float Activities**: These act as unbreakable anchors in the schedule. The leveling engine must NEVER move `is_critical = true` or `total_float_days <= 0`.
- **Leveling Constraints**: If a constraint exists over a critical activity, the engine registers an `unresolvedConstraint: RESOURCE_CONSTRAINT_ON_CRITICAL_PATH` instead of delaying the project.
- **Float Exhaustion**: If moving an activity consumes all its float and it becomes critical, further delays are rejected and flagged as `FLOAT_EXHAUSTED`.

## Validation Proof
- The Test Harness asserts that the output of `generateLevelingRecommendations` contains zero recommendations for the `act-1` (Isolation) critical activity.
- Application of recommendations mathematically links back to the original schedule, proving consistency.
