# M8.12 — Material Readiness Rules

**Status**: LOCKED  
**Date**: 2026-09-01

---

## Material Readiness Status

Each activity's material readiness is computed from its linked material requirements:

| Status | Condition | Color |
|--------|-----------|-------|
| `ready` | All materials: `available >= required` | Green |
| `partial` | Some materials available, not all | Yellow |
| `not_ready` | No materials available, ETA exists | Orange |
| `blocked` | No materials available, no ETA | Red |
| `not_assessed` | No material requirements linked | Grey |

---

## Readiness Percentage

```
readiness_percent = 
  SUM(min(quantity_available, quantity_required)) 
  / SUM(quantity_required) * 100
```

Where quantities are aggregated across all material line items for an activity.

---

## Partial Material Availability

### LOCKED RULE

**Rule: Activity requires ALL critical materials before it can start.**

An activity's `material_constraint_date` is determined by:

```
constraint_date = MAX(eta) across all material requirements
                  WHERE is_critical = true
                  AND quantity_available < quantity_required
```

**Non-critical materials** do not constrain the activity start date. They are tracked for reporting but do not affect the CPM calculation.

### Rationale
In turnaround execution:
- Critical materials (valves, gaskets, flanges) must be on-site before work begins
- Consumables (rags, lubricant) can be procured during execution
- The `is_critical` flag on `workpack_material_lines` already exists

## Minimum Quantity Rule

### RECOMMENDED (Requires User Decision)

```
Option A: All-or-nothing (DEFAULT)
  Activity cannot start until 100% of required critical materials are available.

Option B: Minimum threshold
  Activity can start when >= minimum_start_quantity of each critical material is available.
  This requires a new field: minimum_start_quantity on material_line_id.

Option C: Activity-level threshold
  Activity can start when aggregate material readiness >= X%.
  This requires a new field: material_start_threshold_pct on Activity.
```

**LOCKED DEFAULT**: Option A — All critical materials required.

**UNRESOLVED**: Whether to support Option B or C in M8.12 or defer to M8.13.

## Supply Chain to Constraint Date Flow

```
Material Line: Steel Pipe 6" CS
  quantity_required: 100m
  quantity_available: 60m
  is_critical: true
  
  Supply Record 1: PO-2026-001
    quantity_ordered: 40m
    expected_delivery: 2026-10-15
    status: in_transit

  Result:
    Shortfall: 40m
    Covered by PO: 40m arriving 2026-10-15
    Material Constraint Date: 2026-10-15
    
Activity: Install piping
  planned_start: 2026-10-10
  material_constraint_date: 2026-10-15
  effective_early_start: 2026-10-15 (delayed 5 days)
```

## Edge Cases

| Case | Rule |
|------|------|
| No materials linked | No constraint — `not_assessed` |
| All materials available | No constraint — `ready` |
| Material with no ETA | `blocked` — human intervention required |
| Multiple deliveries for same material | Use latest delivery date that covers shortfall |
| Substitute material available | Substitute can satisfy requirement if flagged |
| Activity already started | Material constraint is informational only |
| Activity complete | Material constraint is ignored |
