# M8.5 — Multi-Tenant Security & IDOR Isolation Audit

This document records the security audit, cross-tenant isolation, and IDOR protection tests for the **Field Execution Control Center**.

---

## 1. Security Vector Matrix

| Test ID | Test Vector | Target Endpoint | Payload & Conditions | Status | Verdict |
|---|---|---|---|---|---|
| **SEC-01** | Cross-Tenant Summary Read | `GET /api/execution/summary?event_id=:tenantA_eventId` | Tenant B session querying Tenant A turnaround event KPIs | HTTP 401 / 403 Forbidden | **PASS** |
| **SEC-02** | Cross-Tenant Board Read | `GET /api/execution/board?event_id=:tenantA_eventId` | Tenant B querying Tenant A activities | HTTP 401 / 403 Forbidden | **PASS** |
| **SEC-03** | Cross-Tenant Activity Mutation | `POST /api/execution/activity-action` | Tenant B attempting to `START`, `UPDATE_PROGRESS`, or `COMPLETE` Tenant A activity | HTTP 400 / 401 / 403 Rejected | **PASS** |
| **SEC-04** | Cross-Tenant Delay Injection | `POST /api/execution/activity-action` (`REPORT_DELAY`) | Tenant B attempting to create constraints in Tenant A workpack | HTTP 400 / 401 / 403 Rejected | **PASS** |
| **SEC-05** | Cross-Tenant Lookahead Query | `GET /api/execution/lookahead?event_id=:tenantA_eventId` | Tenant B querying forecast data of Tenant A | HTTP 401 / 403 Forbidden | **PASS** |
| **SEC-06** | Cross-Tenant Plan vs Actual | `GET /api/execution/plan-vs-actual?event_id=:tenantA_eventId` | Tenant B querying variance data of Tenant A | HTTP 401 / 403 Forbidden | **PASS** |
| **SEC-07** | Cross-Tenant Shift Report | `GET /api/execution/daily-report?event_id=:tenantA_eventId` | Tenant B generating executive daily report of Tenant A | HTTP 401 / 403 Forbidden | **PASS** |

---

## 2. Invariant Guarantees

* **Tenant Scoping Guard:** All routes enforce `withTenantGuard`, verifying `organization_id` in database queries.
* **Granular Role Protection:** Field execution actions require `workpacks.edit` or `workpacks.view` permissions.
* **Zero 500 Internal Errors on Attack:** Unauthorized requests return structured `401 Unauthorized` or `403 Forbidden` responses.
