# M8.7 Phase 2I.6 & 2I.7 - Governance, Audit & Security Hardening

## Implementation Details
The `ResourceLevelingApplyService` was expanded to strictly enforce governance policies during the application of What-If scenarios.

## Enforced Invariants
1. Event existence
2. Organization context validity
3. Target Activity existence
4. **Critical Activity Protections**: The application now explicitly checks `is_critical` during apply and throws `STALE_RECOMMENDATION` if a planner attempts to push a critical activity.
5. Baseline dates drift validation (Start and End)

## Audit Logging
The `AuditLog` metadata payload was expanded to include `scenario_metadata`, providing a durable historical record of exactly what constraints were resolved and how much float was consumed when the planner accepted the recommendation.
