## Activity Type Hierarchy

```
Activity
  ├── Normal Activity (hold_point_type = null)
  ├── Hold Point Activity (hold_point_type = "HOLD")
  │     └── Requires qa_clearance_records before completion
  └── Witness Point Activity (hold_point_type = "WITNESS")
        └── Advisory — qa_clearance_records optional
```
