# M8.4 — Digital Workpack Specification & Contract

This document defines the canonical architecture and contract of the **Digital Workpack Field Execution Workspace** in SYORITY.

---

## 1. Digital Workpack Contract

A canonical Digital Workpack contains 6 core operational dimensions:

```
                          ┌────────────────────────────────┐
                          │   A. Identification & Header   │
                          │   • Workpack ID & Number       │
                          │   • Title, Shutdown, Site      │
                          │   • Unit, System, Asset Tag    │
                          │   • Contractor & Discipline    │
                          │   • Current Lifecycle Status   │
                          └───────────────┬────────────────┘
                                          │
       ┌──────────────────────────────────┼──────────────────────────────────┐
       ▼                                  ▼                                  ▼
┌───────────────┐                  ┌───────────────┐                  ┌───────────────┐
│   B. Scope    │                  │C.Preconditions│                  │   D. QA/QC    │
│• Activities   │                  │• Permit (PTW) │                  │• Hold Points  │
│• WBS & CPM    │                  │• Isolation    │                  │• Clearances   │

│• Est Manpower │                  │• Tools/Rigging│                  │• Sign-Offs    │
└──────┬────────┘                  └───────┬───────┘                  └───────┬───────┘
```

---

## 2. Separation of Planning and Execution

*   **Planning State (Frozen Baseline):**
    *   `Activity.planned_start`, `Activity.planned_end`, `Activity.duration_hours`, CPM Early/Late dates, Total Float, Critical path flags.
*   **Execution State (Field Reality):**
    *   `Activity.actual_start`, `Activity.actual_end`, `Activity.progress_percent`, `Activity.status`.
    *   `Workpack.overall_progress`, `Workpack.status`.
    *   Field changes to actual progress or actual start/end dates **NEVER** overwrite the planned baseline dates.
