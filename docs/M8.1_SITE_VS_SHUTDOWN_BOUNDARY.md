# M8.1 — Site Master Data vs Shutdown Operational Data Boundary

This document defines the strict conceptual and technical separation between permanent **Site Master Data** and transient **Shutdown Campaign Data** in SYORITY.

---

## 1. Structural Separation Principle

```
┌─────────────────────────────────────────────────────────────────┐
│                    PERMANENT SITE FOUNDATION                    │
│   (Created once; shared across all historical/future turnarounds)│
│                                                                 │
│  • Company / Tenant Profile                                     │
│  • Physical Plant Hierarchy (Plant → Area → Unit → System)       │
│  • Asset / Equipment Tag Register (P-1001, E-102, specs)        │
│  • Standard ASME/PCC-1 Flange Torque & Gasket Lookup Matrices   │
│  • Reusable Activity Templates & Standard Work Types            │
│  • Approved Contractor Directories                              │
│  • Standard Certificate & Sign-off Templates                    │
└─────────────────────────────────────────────────────────────────┘
                                │
                                │ (References by Foreign Key)
                                ▼
┌─────────────────────────────────────────────────────────────────┐
│                  TRANSIENT SHUTDOWN CAMPAIGN DATA               │
│         (Scoped to a specific event_id, e.g. TA-2026)           │
│                                                                 │
│  • Shutdown Dates, Milestones, and Target Freeze Timelines      │
│  • Shutdown Scope Register & Justifications                     │
│  • WBS Breakdown & Activity Instances                           │
│  • CPM Critical Path Schedule & Baseline Durations              │
│  • Workpack Assemblies (U10-MEC-001) & Drawing Packages         │
│  • Shift Progress Logs, Actual Start/End, & Field Notes         │
│  • Joint Integrity Bolt Torque Tracking (Live Records)          │
│  • Blind & Spade Install/Removal Manifests                      │
│  • QA/QC Hold Point Inspection Sign-offs & Clearances           │
│  • Daily Safety (HSE) Manhour Logs & Incident Reports           │
│  • Daily Shift Handover Reports & Lookahead PDFs                │
└─────────────────────────────────────────────────────────────────┘
```

---

## 2. Integrity Enforcement Rules

1.  **Never Duplicate Physical Assets:** Creating a new shutdown (`TA-2028`) must NEVER duplicate the Equipment Register, Plant Hierarchy, or ASME Gasket lookup tables. The new shutdown simply references existing `asset_id`, `unit_id`, and `system_id` records.
2.  **Isolated Operational History:** Deleting or resetting a draft shutdown must NEVER cascade-delete physical assets or master standards. It only cleans up records with matching `event_id`.
3.  **Cross-Shutdown Reference Integrity:** An activity or workpack created under `TA-2026` must NEVER be modified or closed by actions taken inside `TA-2028`.
4.  **Preservation of Historic Revisions:** When viewing an archived shutdown (`TA-2024`), the system presents the historical workpacks and progress records frozen as they were during that execution window.
