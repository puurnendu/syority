# M8.7 Phase 2I.1 - Resource KPI Engine

## Implementation Details
The `ResourceKpiService` generates aggregated deterministic KPIs based on output from `ResourcePlanningService.getDemandVsCapacity`. 

## Metrics
- **Total planned demand**: Sum of all baseline demand.
- **Total available capacity**: Sum of all baseline capacity.
- **Deficit / Surplus**: Calculated across the specified event timeframe.
- **Average & Peak Utilization**: Derived securely from capacity/demand variance.
- **Overloaded Days & Hard Shortages**: Accurately mapped to specific constraints.

The results are accessible securely via `GET /api/events/[eventId]/schedule/resource-kpis`.
