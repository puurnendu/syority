# M8.3 — Scheduling Model & Relational Audit

This document records the data model audit of scheduling entities, relationships, constraints, and persistence targets in SYORITY.

---

## 1. Scheduling Entities in `prisma/schema.prisma`

### Input Fields (Authoritative Planner Inputs)
*   `Activity.duration_hours` (`Decimal(8,2)`): Planned work duration in hours.
*   `Activity.planned_start` (`Date`): Planned baseline start.
*   `Activity.planned_end` (`Date`): Planned baseline finish.
*   `Activity.wbs_code` (`String`): Hierarchical WBS code.
*   `ActivityRelationship.predecessor_id` (`UUID`): ID of preceding activity.
*   `ActivityRelationship.successor_id` (`UUID`): ID of succeeding activity.
*   `ActivityRelationship.relationship_type` (`Enum`): `FS` (Finish-to-Start), `SS` (Start-to-Start), `FF` (Finish-to-Finish), `SF` (Start-to-Finish).
*   `ActivityRelationship.lag_days` (`Int`): Offset in days (e.g. `+2` or `-1`).

### Calculated Fields (Persisted or Transient CPM Outputs)
*   `Activity.early_start` (`DateTime?`): Earliest possible start time determined by predecessors.
*   `Activity.early_finish` (`DateTime?`): Earliest possible completion time ($ES + \text{duration}$).
*   `Activity.late_start` (`DateTime?`): Latest allowable start time without delaying project finish.
*   `Activity.late_finish` (`DateTime?`): Latest allowable finish time ($LF - \text{duration}$).
*   `Activity.total_float` (`Decimal?`): Amount of time an activity can slip without delaying project finish ($LS - ES$).
*   `Activity.free_float` (`Float?`): Amount of time an activity can slip without delaying any immediate successor.
*   `Activity.is_critical` (`Boolean?`): Flag indicating if activity is on the critical path ($\text{Total Float} \le 0$).

---

## 2. Multi-Tenant & Shutdown Context Scoping

*   Every calculation must query activities and relationships where:
    ```sql
    organization_id = :sessionOrgId AND event_id = :activeEventId AND deleted_at IS NULL
    ```
*   Cross-shutdown relationships or cross-tenant relationships are strictly forbidden and filtered out by defensive query guards.
