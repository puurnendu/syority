## The Two Dimension Problem

The corpus reveals TWO overlapping but distinct concepts:

| Dimension | Source | Values | Purpose |
|---|---|---|---|
| **Execution Phase** (Window) | Section E "Window" column | PreSD, OP, SD, IR, PostSD | WHEN in the TA lifecycle |
| **Activity Family** | Derived from activity descriptions | PREP, ISO, ACCESS, CLEAN, INSP, DISMANTLE, REPAIR, ASSY, TEST, REST | WHAT kind of work |

## Are They the Same?

> **[FACT]** No. They correlate but do NOT map 1:1.

### Key Mismatches

1. **De-blinding**: Family = ISO, but Phase can be SD or PostSD
2. **Scaffolding removal**: Family = REST, but Phase can be SD
3. **Pre-inspection cleaning**: Family = CLEAN, but Phase = IR (done during inspection phase)
4. **Post-repair inspection**: Family = INSP, but context is within SD phase activities

## RECOMMENDATION

> **[RECOMMENDATION]** Model them as TWO SEPARATE DIMENSIONS.

| Dimension | SYORITY Field | P6 Mapping | Reporting Use |
|---|---|---|---|
| **Execution Phase** | Activity.window (existing) | P6 Activity Code: "Phase" | "SD progress: 72%", "IR progress: 61%" |
| **Activity Family** | ActivityLibrary.work_category (existing) | P6 Activity Code: "Work Family" | "Inspection work: 45 of 80 complete" |

### Management Reporting Benefit

Two dimensions enable richer reporting:

| Report | Dimension Used | Example |
|---|---|---|
| Shutdown Phase Progress | Execution Phase | "SD: 72%, IR: 61%, PostSD: 15%" |
| Work Type Progress | Activity Family | "INSP: 45/80, REPAIR: 30/50, TEST: 5/20" |
| QA Progress | Activity Family + QA Type | "Hold Points: 12/18 cleared" |
| Resource Utilization | Activity Family + Resource | "Welding gangs: 80% utilized" |
| Phase-Family Matrix | Both | "SD/REPAIR: 30/50 activities, IR/INSP: 45/80 activities" |
