## Activity Rule Categories

### Mandatory Activities

**[FACT]** Activities that appear in EVERY workpack of a given equipment type, regardless of job type.

| Activity | Evidence | Equipment Types |
|---|---|---|
| Scaffolding Erection | Present in 26/27 workpacks (96%) | All |
| Blinding | Present in 26/27 workpacks (96%) | All |
| De-blinding | Present in 26/27 workpacks (96%) | All |
| Housekeeping | Present in 14/27 (52%) but mandatory per safety rules | All |
| Insulation Removal | Present in 18/27 (67%) — only missing where no insulation | Most (not simple valves) |
| Insulation Reinstatement | Present in 18/27 (67%) | Where insulation was removed |

### Optional Activities

**[FACT]** Activities that may or may not be included based on planner decision.

| Activity | Condition | Equipment Types |
|---|---|---|
| Rigging Installation | IF rigging_required = true | Heavy lift equipment |
| Spring Support Reading | IF associated piping has springs | Piping, Large Vessels |
| Painting | IF corrosion protection needed | All |
| Booth Preparation | IF hot work (welding) is planned | Where welding is required |

### Conditional Activities

**[RECOMMENDATION]** Activities triggered by inspection findings or specific conditions.

| Activity | Trigger Condition | Equipment Types |
|---|---|---|
| Tube Repair / Retubing | IF tube damage detected during inspection | Heat Exchangers |
| Weld Repair | IF weld defect found during NDT | All welded equipment |
| Coating / Painting | IF corrosion exceeds threshold | Vessels, Columns, Piping |
| Catalyst Loading | IF reactor catalyst change scheduled | Reactors only |
| Hydrotest | IF pressure boundary work performed | All pressure vessels/piping |
| QA Hold Point | IF hold_point_type = HOLD on any activity | Equipment with QA requirements |

## Heat Exchanger Template Example

```
HE-GASKET Template (Simple HE Maintenance)

  MANDATORY:
    1. Scaffolding Erection          [PREP] [PreSD]
    2. Insulation Removal             [PREP] [PreSD]
    3. Tagging                        [PREP] [PreSD]
    4. Blinding                       [ISO]  [OP]
    5. Channel Cover Opening          [ACCESS] [SD]
    6. Cleaning                       [CLEAN] [SD]
    7. ▶ HOLD: Pre-Cleaning Insp      [INSP] [IR]
    8. Box-Up (new gasket)            [ASSY] [SD]
    9. Torquing                       [ASSY] [SD]
   10. De-blinding                    [ISO]  [PostSD]
   11. Insulation Reinstatement       [REST] [PostSD]
   12. Scaffold Removal               [REST] [PostSD]

  OPTIONAL:
    - Rigging Installation            IF rigging_required
    - Painting                        IF painting_m2 > 0
    - Booth Preparation               IF hot work planned

  CONDITIONAL:
    - Hydrotest                       IF pressure boundary opened
    - ▶ HOLD: Post-Hydrotest Insp     IF hydrotest performed
    - Tube Repair                     IF tube damage found
    - Retubing                        IF tube replacement needed
```

**[RECOMMENDATION]** To model Conditional Activities, add: workpack_template_activities.condition_expression (String, nullable). Example: "hydrotest_required = true". The application evaluates this condition when instantiating a template.

**[RECOMMENDATION]** Alternatively, model conditional activities as Optional (is_optional = true) with a descriptive hold_point_description explaining the trigger. This avoids schema change but loses programmatic condition evaluation.
