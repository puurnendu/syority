## Scope Decision

### In M8.12 (P0)
1. Extend `workpack_material_lines` with supply chain fields
2. Create `MaterialSupplyRecord` model
3. Create `MaterialConstraint` model
4. `MaterialReadinessService` — compute readiness from supply data
5. `MaterialScheduleIntegrationService` — inject constraints into CPM
6. Material readiness dashboard UI
7. Material constraint visualization on activities

### In M8.12 (P1)
8. Supplier/vendor tracking
9. PO reference tracking
10. Partial availability readiness percentage
11. Material readiness KPI cards

### Deferred to M8.13 (P2)
12. Substitute material logic
13. Material risk scoring
14. ScenarioMaterialOverride (what-if material delays)
15. Material S-curves
16. SAP integration for real-time stock/PO sync
