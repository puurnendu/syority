| Default duration | `ActivityLibrary` | `duration_hours` | EXISTS |

| Tenant/platform | `ActivityLibrary` | `organization_id` (nullable) | **MODIFIED (D4)** |
| Active state | `ActivityLibrary` | `is_active` | EXISTS |
