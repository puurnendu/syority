# M8.14 — Common Data Model

> **Module**: M8.14 | **Date**: 2026-09-01 | **Type**: READ-ONLY

---

## Core Entity Relationships

```
Organization (1) → (N) Site → (N) Plant → (N) Unit → (N) System → (N) Asset
Organization (1) → (N) Event (turnaround)
Event (1) → (N) Workpack → (N) Activity → (N) ActivityResource
Event (1) → (N) SafetyLog / SafetyIncident
Event (1) → (N) EvmSnapshot
Asset (1) → (N) Workpack (via asset_id FK)
Activity (1) → (N) MaterialConstraint
Activity (1) → (N) ProgressLog
Activity (1) → (1) StandardActivityType (M8.13)
Asset (1) → (1) EquipmentType (M8.13)
```

## Data Model Integrity

| Relationship | FK Enforced | Optional | Indexed |
|-------------|------------|----------|---------|
| Activity → Workpack | ✅ | Yes | ✅ |
| Activity → Event | ❌ No FK | Yes (via workpack.event_id) | — |
| Workpack → Event | ✅ | Yes | — |
| Workpack → Asset | ✅ | Yes | — |
| Asset → System | ✅ | Yes | — |
| Asset → Unit | ✅ | Yes | — |
| Asset → Plant | ✅ | Yes | — |
| System → Unit | ✅ | Yes | — |
| Unit → Plant | ✅ | Yes | — |

**Finding**: ⚠️ Most hierarchy links are OPTIONAL. An asset can exist without a plant/unit/system. This is flexible but makes hierarchy queries unreliable.
