# M8.5 — Document Template Model

## Architecture

```
Equipment Type + Job Type
        ↓
Activity Template (workpack_templates)
        ↓
Workpack Data (activities, resources, UDFs, QA)
        ↓
Report Definition (report_definitions)
        ↓
Report Sections (report_sections)
        ↓
Data Provider (report_data_providers)
        ↓
PDF Generator (report_generations / report_artifacts)
```

## Existing Infrastructure

### DocumentTemplate (basic)
- `id`, `organization_id`, `name`, `document_type`, `description`
- `default_sections` (JSON)
- Used for simple document types

### Report Builder (enterprise)
- `report_definitions` — template identity, data_source_key, output format
- `report_sections` — ordered sections with types:
  - `data` — tabular data
  - `chart` — bar/pie/line/scurve/histogram
  - `kpi_cards` — KPI summary cards
  - `summary` — narrative text
  - `signature` — sign-off blocks
  - `photos` — image gallery
- `report_data_providers` — registry of provider classes
- `report_branding_profiles` — logos, colors, fonts
- `report_layouts` — page layout configuration
- `report_generations` — generated PDF artifacts

### Separation: Activity Template ≠ Document Template

| Concern | Model | Purpose |
|---|---|---|
| Activity Template | `workpack_templates` + `workpack_template_activities` | What activities exist, relationships, resources, QA |
| Document Template | `report_definitions` + `report_sections` | Document structure, layout, sections, data bindings |

These are SEPARATE concepts. A single activity template can be rendered through multiple document templates (e.g., workpack issue sheet, QA checklist, progress report).

## Workpack PDF Generation Flow

```
1. Planner selects workpack
2. System selects report_definition (matched by equipment_type / job_type)
3. Report sections define document structure
4. Each section queries its data_provider for workpack-specific data
5. BrandingService applies org logo, colors, fonts
6. PDF renderer produces output
7. report_artifact stores file reference
```

## Report Sections for a Workpack

| Section Key | Type | Data Source |
|---|---|---|
| `cover_page` | summary | Workpack header fields |
| `scope_of_work` | data | workpack.scope_of_work |
| `activity_schedule` | data | Activities with start/end/duration |
| `resource_summary` | data | ActivityResource aggregates |
| `material_list` | data | WorkpackMaterial lines |
| `safety_requirements` | data | template safety_json |
| `qa_checklist` | data | qa_clearance_records, hold points |
| `blind_register` | data | Blind records |
| `joint_integrity` | data | JointIntegrityItem records |
| `sign_off` | signature | Approval signatures |
