# M8.7 Phase 2I.2 - Resource Forecast Engine

## Implementation Details
The `ResourceForecastService` processes daily capacity and demand aggregations specifically to output time-series predictions.

## Forecast Output
- **Shortage Predictions**: Identifies the first shortage date, peak shortage date, and maximum forecast deficit.
- **Status Classification**:
  - `NORMAL`: < 80% utilization
  - `WATCH`: 80-90% utilization
  - `AT_RISK`: 90-100% utilization
  - `CRITICAL`: > 100% utilization or any absolute deficit
- **Consecutive Shortages**: A critical metric counting how many days back-to-back a resource is overallocated, serving as a heuristic for CPM slip.
