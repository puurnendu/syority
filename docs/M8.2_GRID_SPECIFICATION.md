# M8.2 — Activity Planning Grid Specification

This document defines the user interface column definitions, editing behaviors, keyboard navigation bindings, and data synchronization rules for the **ActivityPlanningGrid**.

---

## 2. Keyboard Navigation Engine

The grid operates as a virtualized spreadsheet with strict keyboard shortcuts:

*   **Enter:** Commits current cell value and moves focus down to the cell below.
*   **Tab:** Commits current cell value and moves focus to the next cell to the right.
*   **Shift + Tab:** Moves focus to the previous cell to the left.
*   **Up / Down / Left / Right Arrows:** Moves active cell focus in the respective direction.
*   **Double-Click / Space / F2:** Enters in-place cell editing mode.
*   **Escape:** Cancels editing, reverts to previous cell value, and exits edit mode.
*   **Ctrl + C / Cmd + C:** Copies selected cell(s) or rows to clipboard.
*   **Ctrl + V / Cmd + V:** Triggers Excel TSV clipboard paste handler.
*   **Delete / Backspace:** Clears content of selected cell(s).

## 3. Date & Duration Arithmetic

*   When `planned_start` and `duration_hours` are provided:
    $$\text{planned\_end} = \text{planned\_start} + \left\lceil \frac{\text{duration\_hours}}{8} \right\rceil \text{ days}$$
*   When `planned_start` and `planned_end` are modified:
    $$\text{duration\_hours} = (\text{planned\_end} - \text{planned\_start} \text{ in days} + 1) \times 8\text{ hours}$$
