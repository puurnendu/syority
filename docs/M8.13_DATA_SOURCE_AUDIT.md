# M8.13 Data Source Audit

## Field-Level Data Ownership & Classification

### Activity Model (Authoritative Execution Record)

| Field | Type | Classification | Owner | Consumed By |
|-------|------|---------------|-------|-------------|
| `progress_percent` | Int? (0-100) | **AUTHORITATIVE** | Activity CRUD / WhatsApp / Field Execution | EVM, Dashboard, Reports, Schedule Health, Rollups |
| `status` | ActivityStatus enum | **AUTHORITATIVE** | Activity CRUD | Dashboard, Execution Board, Reports |
| `planned_start` | DateTime? | **AUTHORITATIVE** (post-CPM) | Schedule Engine → Activity | EVM PV calc, Schedule Health, Variance, Forecasts |
| `planned_end` | DateTime? | **AUTHORITATIVE** (post-CPM) | Schedule Engine → Activity | EVM PV calc, Schedule Health, Variance, Forecasts |
| `actual_start` | DateTime? | **INPUT** | Manual entry / Field Execution | EVM, Dashboard, Forecast |
| `actual_end` | DateTime? | **INPUT** | Manual entry / Field Execution | EVM, Dashboard, Forecast |
| `duration_hours` | Decimal? | **AUTHORITATIVE** | Activity CRUD / Template instantiation | Progress weighting, EVM, CPM |
| `budgeted_cost` | Float? | **INPUT** | Manual entry / Baseline creation | EVM BAC |
| `actual_cost` | Float? | **INPUT** | Manual entry | EVM AC (UD-3 Decision A) |
| `remaining_duration` | Float? | **DERIVED** (should be) | ScheduleForecastService | Forecast calculations |
| `early_start/finish` | DateTime? | **DERIVED** | Schedule Engine (CPM forward pass) | Critical path, float, EVM |
| `late_start/finish` | DateTime? | **DERIVED** | Schedule Engine (CPM backward pass) | Critical path, float |
| `total_float` | Decimal? | **DERIVED** | Schedule Engine | Critical path, Schedule Health |
| `is_critical` | Boolean? | **DERIVED** | Schedule Engine (float=0 check) | Critical path displays, EVM drilldown |
| `work_category` | String? | **INPUT** | Manual / Template | EVM earning rule selection |
| `activity_library_id` | UUID? | **INPUT** (sparse) | Template instantiation | Activity classification (underused) |

## Data Flow Summary

```
User Input (progress %, dates, costs)
       ↓
Activity Table (authoritative execution record)
       ↓ (written)
ProgressLog (audit trail)
       ↓ (read)
FieldExecutionService (duration-weighted progress)  ←── Execution Dashboard
       ↓ (async/manual)
Workpack.overall_progress (CACHED, stale risk)      ←── Reports, SummaryBar
       
Activity Table (same record)
       ↓ (read independently)
portfolio-stats API (simple average progress)       ←── Main Dashboard
       ↓ (inline calculation)
Different SPI/CPI than M8.10

Activity Table (same record)
       ↓ (read independently)
EvmSnapshotService → EvmCalculationService          ←── EVM Dashboard
       ↓ (BAC × progress / 100)
Authoritative EVM (but different from dashboard SPI)
```
