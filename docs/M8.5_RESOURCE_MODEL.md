# M8.5 — Resource Model

## Architecture

```
ActivityLibrary (PLATFORM/TENANT)
        ↓ activity_code_default_resources
Default Resource Profile
        ↓ workpack_templates.resources_json (override)
Template Resource Profile
        ↓ TemplateLibraryService.instantiate() [D2 FIX]
ActivityResource (activity-level)
        ↓ Planner review
Confirmed Resource Assignment
```

## Existing Schema (NO changes required)

### ResourceType
- `id`, `organization_id`, `discipline_id`
- `name`, `code`
- `is_active`

### Resource
- `id`, `organization_id`, `site_id`
- `resource_type_id` → ResourceType
- `contractor_id` → Contractor
- `name`, `employee_id`, `craft_code`
- `is_active`

### ActivityResource
- `id`, `organization_id`, `workpack_id`, `activity_id`
- `resource_type_id` → ResourceType
- `resource_id` → Resource
- `contractor_id` → Contractor
- `planned_hours`, `actual_hours`, `headcount`
- `resource_type` (enum: labor/material/equipment)
- `resource_name`, `crew_size`, `quantity`, `unit`

### activity_code_default_resources
- `id`, `organization_id`
- `library_id` → ActivityLibrary
- `resource_id` → Resource
- `quantity` (Decimal)
- `@@unique([library_id, resource_id])`

## Inheritance Chain

| Level | Source | Override? |
|---|---|---|
| 1. System Default | `activity_code_default_resources` (PLATFORM library) | Base |
| 2. Tenant Default | `activity_code_default_resources` (TENANT library) | Overrides system |
| 3. Template Override | `workpack_templates.resources_json` | Overrides tenant |
| 4. Activity Override | `ActivityResource` (planner edit) | Final |

## D2 Fix Implementation

During `TemplateLibraryService.instantiate()`:

1. For each created activity with `activity_code`:
   - Query `ActivityLibrary` matching code (prefer TENANT, fall back to PLATFORM)
   - Query `activity_code_default_resources` for that library entry
   - Create `ActivityResource` rows with default quantities
2. If template `resources_json` has overrides, apply those instead
3. Update `WorkpackInstantiation.resources_created` count

## Planner Workflow

```
Template instantiation
    ↓
Resources auto-populated (default quantities)
    ↓
Planner reviews resource list
    ↓
Planner adjusts headcount / hours / removes unnecessary
    ↓
Resources confirmed
```

## Auditability

| State | How to determine |
|---|---|
| Default (never modified) | `ActivityResource.created_at` = workpack creation time, no manual edits |
| Planner confirmed | `ActivityResource.updated_at` > `created_at` |
| Override | Compare `ActivityResource.quantity` vs `activity_code_default_resources.quantity` |
