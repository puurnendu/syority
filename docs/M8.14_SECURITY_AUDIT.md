## Tenant Isolation

| Layer | Mechanism | Status |
|-------|-----------|--------|
| Database queries | `organization_id` WHERE clause | ⚠️ Most routes but not enforced at service layer |
| API routes | `orgScope(session)` extracts org_id | ✅ Where used |
| Prisma middleware | None (no row-level security) | ❌ Not implemented |
| Event isolation | `event_id` in queries | ✅ Where used |

**Finding**: No Prisma middleware enforces `organization_id` filtering. Each route must manually add `organization_id` to queries. This is a **systemic risk** — a missed filter could expose cross-tenant data.
