## PHASE 2: DATABASE / PRISMA FINAL AUDIT

- **Migration Status:** M8.8 migration successfully applied.
- **Data Integrity Risk Found:** `ScheduleBaseline.is_current` uses a standard index (`@@index([event_id, is_current])`) instead of a partial unique constraint. While the `ScheduleBaselineService` uses a Prisma transaction to toggle `is_current` flags sequentially, the database itself does not prevent a race condition from creating two current baselines for the same event.
  - **Classification:** Data-integrity risk (P2). See Known Issues.
