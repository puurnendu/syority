## Activity Family vs Execution Phase: CONFIRMED INDEPENDENT

### XER Evidence

**[FACT]** The P6 XER has SEPARATE Activity Code Types for Level Code (activity classification) and Phase (execution timing). They are independently assigned to activities.

### Phase Values (7, not 5)

| HO | Handover | 212 | Pre-shutdown: Operations hands over equipment |

### Phase-Level Code Independence Examples

| Activity | Level Code | Phase | Why Independent |
|---|---|---|---|
| Blinding | AFC.BLD (→ISO.BLINDING) | OP | Isolation done during Operations phase |
| De-blinding | AFC.DB (→ISO.DEBLINDING) | CP or TO | De-isolation done during Commissioning or Takeover |
| NDT | PIP.NDT (→INSP.NDT) | IR | Inspection during IR phase |
| Box-up | V&T.Box (→ASSY.BOXUP) | IR or CP | Assembly can span IR and CP |

**[RECOMMENDATION]** SYORITY must maintain Phase and Level Code as INDEPENDENT dimensions on every activity.
