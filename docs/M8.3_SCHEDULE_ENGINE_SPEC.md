# M8.3 — Schedule Engine Specification & CPM Algorithm Design

This document defines the mathematical algorithms, data structures, cycle detection logic, and API interface for the **SYORITY Deterministic CPM Schedule Engine**.

---

## 1. Mathematical Algorithm & Pipeline

```
  1. Input Activities & Relationships
               │
               ▼
  2. Graph Construction & Cycle Detection (Kahn's Algorithm)
               │
          Is Cycle Detected?
         ├── YES ──► Return SCHEDULE_CYCLE_DETECTED (nodes, edges)
         └── NO
               ▼
  3. Forward Pass CPM
     • Compute Early Start (ES) & Early Finish (EF)
     • Project Finish Date = max(EF_i)
               │
               ▼
  4. Backward Pass CPM
     • For activities without successors: LF_i = Project Finish
     • Compute Late Finish (LF) & Late Start (LS)
               │
               ▼
  5. Float & Critical Path Computation
     • Total Float = LS_i - ES_i
     • Free Float = min_{s \in Succ}(ES_s - lag) - EF_i
     • is_critical = (Total Float <= 0)
               │
               ▼
  6. Return Schedule Result Object
```

---

## 2. Relationship Type Formulas

Let $D_i$ be the duration of activity $i$, and $L_{ij}$ be the lag between predecessor $i$ and successor $j$.

### Forward Pass (Computing $ES_j$ and $EF_j$)
*   **Finish-to-Start (FS):**
    $$ES_j = \max_{(i, j)} (EF_i + L_{ij})$$
*   **Start-to-Start (SS):**
    $$ES_j = \max_{(i, j)} (ES_i + L_{ij})$$
*   **Finish-to-Finish (FF):**
    $$EF_j = \max_{(i, j)} (EF_i + L_{ij}), \quad ES_j = EF_j - D_j$$
*   **Start-to-Finish (SF):**
    $$EF_j = \max_{(i, j)} (ES_i + L_{ij}), \quad ES_j = EF_j - D_j$$
*   **Default Duration:**
    $$EF_j = ES_j + D_j$$

### Backward Pass (Computing $LF_i$ and $LS_i$)
*   **Finish-to-Start (FS):**
    $$LF_i = \min_{(i, j)} (LS_j - L_{ij})$$
*   **Start-to-Start (SS):**
    $$LS_i = \min_{(i, j)} (LS_j - L_{ij})$$
*   **Finish-to-Finish (FF):**
    $$LF_i = \min_{(i, j)} (LF_j - L_{ij})$$
*   **Start-to-Finish (SF):**
    $$LS_i = \min_{(i, j)} (LF_j - L_{ij})$$
*   **Default Duration:**
    $$LS_i = LF_i - D_i$$

## 3. TypeScript Engine Interface (`src/lib/scheduleEngine.ts`)

```typescript
export interface ScheduleActivityInput {
  id: string;
  activity_number?: string;
  description: string;
  duration_hours: number;
  planned_start?: string | Date | null;
  planned_end?: string | Date | null;
  wbs_code?: string | null;
  status?: string;
}

export interface ScheduleRelationshipInput {
  id?: string;
  predecessor_id: string;
  successor_id: string;
  relationship_type?: 'FS' | 'SS' | 'FF' | 'SF';
  lag_days?: number;
}

export interface ScheduleCalculationOptions {
  project_start_date?: string | Date;
  working_hours_per_day?: number; // default: 8 or 24 for turnaround
  critical_float_threshold?: number; // default: 0
}

export interface ScheduleCalculationResult {
  success: boolean;
  error?: string;
  cycle_detected?: boolean;
  cycle_node_ids?: string[];
  project_start: string;
  project_finish: string;
  total_duration_days: number;
  critical_path_ids: string[];
  activities: CalculatedActivity[];
  warnings: ScheduleWarning[];
}
```
