## Template Architecture

**[FACT]** The existing TemplateFamily → WorkpackTemplate → TemplateActivity hierarchy is correct.

### Template Activity Enrichment

Each template activity should now carry:
- Activity description
- Canonical SYORITY Level Code (Family.Type)
- Native iPlan Level Code(s)
- Default phase
- Default duration
- QA AI stage (if applicable)
- QA TS stage (if applicable)
- UDF definitions (which quantities apply)
- is_optional flag
- condition_expression (for conditional activities)
- Predecessor sequence

**[RECOMMENDATION]** The template must provide enough information to generate a complete workpack that can be exported to P6 WITHOUT the user manually assigning Activity Codes.
