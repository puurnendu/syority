# M8.5 — Plan vs. Actual Variance & Schedule Integrity

This document defines the mathematical formulation, variance rules, and isolation guarantees between **Planning Baseline Dates** and **Field Execution Actuals** in SYORITY.

---

## 1. Mathematical Variance Formulas

```
┌───────────────────────────────────────────────┐
│               VARIANCE ENGINE                 │
├───────────────────────────────────────────────┤
│  Start Variance (Days/Hours):                 │
│    ΔStart = Actual_Start - Planned_Start      │
│    • ΔStart > 0: Delayed Start                │
│    • ΔStart = 0: On-Time Start                │
│    • ΔStart < 0: Early Start                  │
│                                               │
│  Finish Variance (Days/Hours):                │
│    ΔFinish = Actual_Finish - Planned_Finish   │
│    • ΔFinish > 0: Delayed Finish              │
│    • ΔFinish = 0: On-Time Finish              │
│    • ΔFinish < 0: Early Finish                │
│                                               │
│  Duration Variance:                           │
│    ΔDuration = Actual_Duration - Planned_Dur  │
└───────────────────────────────────────────────┘
```

---

## 2. Integrity Guarantees

1. **Strict Immutability of Planning Baseline:**
   * `Activity.planned_start`, `Activity.planned_end`, and `Activity.duration_hours` are frozen baseline values.
   * Modifying `Activity.actual_start` or `Activity.actual_end` records operational history without touching planned dates.
2. **CPM Independence:**
   * Early Start, Early Finish, Late Start, Late Finish, Total Float, Free Float, and Critical Path flags are calculated deterministically by the CPM schedule engine based on baseline logic.
   * Progress or actual dates recorded by field supervisors **DO NOT** trigger automatic schedule shifts or recalculate CPM float unless an authorized planner explicitly runs `/api/schedule/calculate`.
3. **Audit Transparency:**
   * All progress and actual adjustments are logged with timestamp, user ID, and optional field comments.
