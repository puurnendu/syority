### Gap Analysis

**Reports 2 and 3** require that Activity records have a link back to ActivityLibrary.
Activity model already has `activity_library_id` (nullable). When activities are instantiated from templates, this link should be populated.

**[FINDING]** The link `activity.activity_library_id` exists but may not always be populated during template instantiation. This is a code-level issue, not a schema issue.
