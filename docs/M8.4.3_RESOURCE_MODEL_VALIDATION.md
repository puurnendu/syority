## Manpower vs Man Hours Analysis

### Is "Manpower" = Number of People?

**[FACT]** YES. The corpus format is explicit: "Cold Gang (8 Manpower): 3.00;" means 8 people for 3 hours.

### Is "Sum of Estimated Man Hours" = Manpower × Duration?

**[INFERENCE]** YES — with qualification. The formula is: Σ(crew_headcount × crew_duration) for all crew entries on the activity.

**Example (Boiler WP 9000009550, Activity "External Scaffolding"):**

```
Manpower: Scaffolding Gang (15 Manpower): 10.00
Sum of Estimated Man Hours: 150.00
Verification: 15 × 10 = 150 ✅
```

## SYORITY Schema Compatibility

**[FACT]** ActivityResource model is well-structured for this data:

```
ActivityResource {
  resource_type: "labor"      // or "non_labor"
  resource_name: "Cold Gang"  // crew type
  headcount: 8               // manpower count
  crew_size: 8               // same as headcount for labor
  planned_hours: 3.0         // crew duration
  // Calculated: man_hours = headcount × planned_hours = 24
}
```
