# M8.4.7 — Optional Export Architecture

> **M8.4.7** — SYORITY Activity Knowledge Bank — Generated: 2026-08-18T07:08:59.148Z
> Classification: FACT | INFERENCE | RECOMMENDATION | UNKNOWN
> Principle: SYORITY is the System of Record. P6 is an optional export.

## Core Principle
> Every SYORITY attribute exists natively.
> Export is an OUTPUT ADAPTER, not a dependency.

## Export Target Types
| Target | Description |
|---|---|
| P6_NATIVE_FIELD | Standard P6 activity field (Name, Duration, Progress) |
| P6_ACTIVITY_CODE | P6 Activity Code Type with enumerated values |
| P6_UDF | P6 User Defined Field (text/number/date) |
| NOT_EXPORTED | SYORITY-only, not included in any export |
