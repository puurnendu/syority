## Template Architecture
```
Knowledge Bank (what activities exist)
    ↓
Template Library (which activities for this equipment+job)
    ↓
Workpack (instantiated activities with planner customization)
```

## Template Instantiation Flow
1. Planner selects Equipment Type
2. Planner selects Job Type (from applicable templates)
3. Template loads activities with:
   - Mandatory activities (cannot be removed)
   - Optional activities (planner decides)
   - Conditional activities (planner evaluates condition)
4. Planner enters quantities for applicable UDFs
5. Planner reviews and adjusts durations
6. Planner assigns resources
7. Workpack enters scheduling flow
