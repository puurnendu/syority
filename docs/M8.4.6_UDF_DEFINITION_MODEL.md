## CRITICAL CORRECTION — What is a "UDF"?

### Previous Assumption (M8.4.2-M8.4.5)
"UDFs" was used loosely to refer to all activity-level custom fields, including scaffolding, painting, insulation, and rigging.

### Forensic Finding
**[FACT]** In the iPlan/P6 ecosystem, these terms have precise meanings:

| Term | iPlan Meaning | P6 Meaning | SYORITY Meaning |
|---|---|---|---|
| **Activity Code** | Field exported with enumerated values via iPlan config (id=1) | P6 Activity Code Type with discrete code values | Classification dimension |
| **UDF** | Field exported as free-form data via iPlan config (id=2) | P6 User-Defined Field on TASK table | Arbitrary metadata |
| **Planning Quantity** | iPlan Operation CustomNumber fields | ❌ NOT in P6 | ActivityUdfValue.value_number |

### The Three Field Types in SYORITY

**[RECOMMENDATION]** SYORITY should model three distinct concepts:

#### 1. Activity Codes (Classification)
These are ENUMERATED classification dimensions. They have a fixed set of values.

| Field | Values | Source |
|---|---|---|
| Level Code | 41 native codes | iPlan CustomDropDownList1 → P6 Activity Code |
| Phase | 7 values | iPlan → P6 Activity Code |
| Discipline | 6 values | iPlan → P6 Activity Code |

#### 2. UDF Definitions (Quantity Templates)
These define WHAT quantities can be tracked for an activity type.

| UDF Definition | Unit | Applicable Activities | Progress-Driving |
|---|---|---|---|
| Scaffolding Volume | m³ | PREP.SCAFFOLDING, REST.SCAFFOLD_REMOVE | YES |
| Painting Area | m² | REPAIR.PAINTING, REPAIR.COATING | YES |
| Insulation Area | m² | PREP.INSUL_REMOVAL, REST.INSUL_REINSTATE | YES |
| Welding Quantity | inch-dia | REPAIR.WELDING | YES |
| Rigging Plan Required | boolean | Any activity needing rigging | NO (flag) |

#### 3. UDF Values (Planner-Entered + Field-Entered)
These are the ACTUAL values entered by planners (planned) and execution teams (actual).

| Stage | Who Enters | Example |
|---|---|---|
| Planned | Planner | Scaffolding Planned = 4,500 m³ |
| Actual | Field Supervisor | Scaffolding Actual = 3,200 m³ |
| Remaining | Calculated | 4,500 - 3,200 = 1,300 m³ |
| Progress | Calculated | 3,200 / 4,500 = 71.1% |
