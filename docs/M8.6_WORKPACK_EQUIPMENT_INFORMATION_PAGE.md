# M8.6 Workpack Equipment Information Page

## 1. Objective
Provide a standardized, generated PDF page within the Workpack containing all verified Equipment Knowledge for the target asset. This avoids planners manually copying reference information into PDF builders or relying on scattered technical datasheets.

## 2. Page Location
- **Proposed Position:** Immediately following the Workpack Cover Page and Index, and just before the detailed Job Scope / Activity Execution sequence.
- **Why?** It acts as the primary reference context for the execution crew. Before diving into the "How" (the activities), they are grounded in the "What" (the equipment specifications).

## 3. Dynamic Field Rendering
The `PdfService.ts` will **not** hardcode fields (like `Tube OD` or `Bundle Weight`). 
Instead, it will dynamically query the `EquipmentKnowledgeMaster` (the active verified fields for the asset) and group them by the underlying `EquipmentType`.

### Data Fetching
```typescript
const knowledgeFields = await prisma.equipmentKnowledgeField.findMany({
  where: { 
    asset_id: workpack.asset_id,
    verification_status: 'VERIFIED'
  },
  orderBy: { field_name: 'asc' }
});
```

### Presentation Structure
The page will render in a two-column layout table:

```text
--------------------------------------------------
EQUIPMENT INFORMATION
--------------------------------------------------
Equipment Tag:        [asset.tag_number]
Equipment Name:       [asset.name]
Equipment Type:       [asset.asset_type]
Service Description:  [asset.service_description]
--------------------------------------------------
TECHNICAL INFORMATION
--------------------------------------------------
Field                 Value       Unit
--------------------------------------------------
[field_name]          [value]     [unit]
[field_name]          [value]     [unit]
...
```

## 4. Reusability
Because this data is pulled from the canonical Equipment Knowledge base, when an identical Heat Exchanger requires a new Workpack 3 years from now, the `PdfService` will instantly inject this rich technical data into the new Workpack without any planner intervention.
