## Progress Calculation
```
Quantity-Based Progress:
  Progress % = Actual Quantity / Planned Quantity × 100

Duration-Based Progress:
  Progress % = Σ(activity.progress × activity.duration) / Σ(activity.duration)

QA-Based Progress:
  Progress % = Cleared Hold Points / Total Hold Points × 100
```

## Data Flow
```
Planner creates workpack
    ↓
Template loads activity + applicable UDF definitions
    ↓
Planner enters Planned Quantities (ActivityUdfValue)
    ↓
Field supervisor enters Actual Quantities (ProgressLog daily)
    ↓
Dashboard calculates Progress = Actual / Planned
```
