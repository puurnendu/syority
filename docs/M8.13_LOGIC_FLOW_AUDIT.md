# M8.13 Logic Flow Audit

## End-to-End KPI Trace

### KPI 1: Overall TA Progress (%)

#### Implementation A — Execution Dashboard (FieldExecutionService)

```
DATABASE: Activity.progress_percent, Activity.duration_hours
    ↓
PRISMA: prisma.activity.findMany({ select: { duration_hours, progress_percent } })
    ↓
SERVICE: FieldExecutionService.calculateWeightedProgress()
    ↓  METHOD: Duration-weighted
    ↓  FORMULA: Σ(progress × duration) / Σ(duration)
    ↓  FALLBACK: simple average if all durations = 0
    ↓
API: /api/events/[eventId]/execution → { overall_progress: N }
    ↓
FRONTEND: ExecutionCockpit.tsx L386 → displays summary.overall_progress
    ↓
DASHBOARD: Execution Cockpit — "Overall Progress: N%"
```

**Classification: AUTHORITATIVE** (best implementation, duration-weighted)

#### Implementation B — Portfolio Dashboard (portfolio-stats API)

```
DATABASE: Activity.progress_percent (grouped by workpack_id)
    ↓
PRISMA: prisma.activity.groupBy({ by: ['workpack_id'], _avg: { progress_percent } })
    ↓
API INLINE: progressMap[wpId] = Math.round(row._avg.progress_percent ?? 0)
    ↓  Then: avgProgress = Σ(progressMap[w.id]) / workpack_count
    ↓  METHOD: Simple average per workpack, then simple average across workpacks
    ↓
API: /api/dashboard/portfolio-stats → { avg_progress: N }
    ↓
FRONTEND: PortfolioDashboard.tsx L191 → displays s.avg_progress
    ↓
DASHBOARD: Main Dashboard — "Avg Progress: N%"
```

**Classification: INCONSISTENT — unweighted, double-averaged**

#### Implementation C — Report Providers (Workpack.overall_progress)

```
DATABASE: Workpack.overall_progress (CACHED field)
    ↓
PRISMA: prisma.workpack.findMany({ select: { overall_progress } })
    ↓
PROVIDER: ContractorProgressProvider → Σ(overall_progress) / count
    ↓  Also: DisciplineProgressProvider → same pattern
    ↓  METHOD: Simple average of CACHED values
    ↓
REPORT: "Contractor Progress: N%", "Discipline Progress: N%"
```

**Classification: STALE RISK — reads cached field that may not be current**

### KPI 2: SPI (Schedule Performance Index)

#### Implementation A — M8.10 EVM (Authoritative)

```
DATABASE: Activity.progress_percent, BaselineActivity.budgeted_cost, planned_start/finish
    ↓
SERVICE: EvmCalculationService.calculateEv() → BAC × min(progress/100, 1.0)
    ↓ SERVICE: EvmCalculationService.calculatePv() → BAC × linear_interpolation
    ↓
AGGREGATION: calculateEventEvm() → totalEV / totalPV
    ↓
API: /api/events/[eventId]/evm → { summary: { spi: N } }
    ↓
DASHBOARD: CostControlDashboard
```

**Classification: AUTHORITATIVE (cost-weighted)**

#### Implementation B — Portfolio Stats (DUPLICATE)

```
DATABASE: Activity.progress_percent, duration_hours, planned_start/end, ProgressLog.manhours_actual
    ↓
API INLINE (L240-263):
    EV = Σ(duration × progress / 100)
    PV = Σ(duration × time_interpolation)
    AC = Σ(ProgressLog.manhours_actual)  ← DIFFERENT AC SOURCE!
    SPI = EV / PV
    ↓
API: /api/dashboard/portfolio-stats → { spi: N }
    ↓
DASHBOARD: Main Dashboard
```

**Classification: DUPLICATE INCONSISTENT** — uses duration instead of BAC, ProgressLog.manhours_actual instead of Activity.actual_cost

#### Implementation C — Schedule Health (DUPLICATE)

```
DATABASE: Activity.progress_percent, duration_hours, planned_start/end
    ↓
SERVICE: ScheduleHealthService.scoreProgressEarned() (L459-506)
    EV analog = Σ(progress × duration)
    PV analog = Σ(time_interpolation × 100 × duration)
    SPI analog = EV / PV × 100
    ↓
API: /api/events/[eventId]/schedule/health
    ↓
DASHBOARD: Schedule Control Dashboard
```

**Classification: DUPLICATE INCONSISTENT** — different formula structure, no AC

### KPI 3: Workpack Progress (%)

#### Writer A — FieldExecutionService.syncWorkpackProgress()

```
TRIGGER: Called manually / by certain update flows
    ↓
QUERY: Activities where workpack_id = X, status ≠ cancelled
    ↓
CALC: calculateWeightedProgress() → duration-weighted
    ↓
WRITE: prisma.workpack.update({ data: { overall_progress: N } })
```

#### Writer B — WhatsApp Approve Route

```
TRIGGER: WhatsApp progress approval
    ↓
QUERY: Activities where workpack_id = X
    ↓
CALC: Σ(progress_percent) / activities.length → SIMPLE AVERAGE
    ↓
WRITE: prisma.workpack.update({ data: { overall_progress: N } })
```

**INCONSISTENCY**: Writer A uses duration-weighted, Writer B uses simple average. Both write to the same field. Last write wins.
