# M8.7 Phase 2F.5 - UI Acceptance

## Acceptance Workflow

**Step 1: Open Planner Workspace**
- Navigate to the Gantt / Schedule view.

**Step 2: Select Resources**
- Open the Resource Loading panel.

**Step 3: Confirm Loading**
- Visually verify that the Resource Loading, Resource Availability, and Constraints match backend values.

**Step 4: Create Intentional Overload**
- Ensure that Capacity = 10, Demand = 18 for a specific resource type. 
- UI must display `OVER-ALLOCATED Variance = -8`.

**Step 5: Execute Simulation**
- Click the `Level` action button in the toolbar.

**Step 6: Preview Verification**
- The modal displays: Activity, Original Start, Original End, Proposed Start, Proposed End, Float Consumed, Reason.
- **Step 7:** Verify critical activities (0 total float) are excluded from the proposed delays.

**Step 8: Approve**
- Click `Accept & Apply`.

**Step 9: State Refresh Verification**
- **Gantt:** The task bars physically move to the right.
- **Resource Loading:** The histogram levels out, eliminating the previous constraint.
- **Float/Critical Path:** The data grid correctly recalculates `total_float` based on the new dates.
- **Constraints:** The constraint badge clears.

**Step 10: Legacy Functionality**
- Verify `app/api/schedule/resource-histogram/route.ts` and `src/components/Schedule/ResourceHistogram.tsx` continue to function without disruption.
