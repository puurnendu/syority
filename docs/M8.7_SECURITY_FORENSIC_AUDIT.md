## 5. Stale Recommendation IDOR Protection

**File:** `ResourceLevelingApplyService.ts`

The apply endpoint performs validation against IDOR attacks on recommendations:
1. ✅ Validates event ownership: `prisma.event.findFirst({ where: { id: eventId, organization_id: organizationId } })`
2. ✅ Validates activities belong to event AND org: `prisma.activity.findMany({ where: { id: { in: activityIds }, organization_id: organizationId, workpack: { event_id: eventId } } })`
3. ✅ Validates baseline drift (planned_start/planned_end match)
4. ✅ Blocks modification of critical activities
5. ✅ Rejects cancelled/deleted activities
