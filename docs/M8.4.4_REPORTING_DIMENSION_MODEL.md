### Key Matrix Reports Supported Natively
- **Phase by Equipment Type**: (e.g., SD progress for all Heat Exchangers)
- **Family by Unit**: (e.g., INSP progress for FCC Unit)
- **Quantity by Event**: (e.g., Total Scaffolding m³ planned vs actual for entire Shutdown)
- **QA by Phase**: (e.g., Hold Points cleared during IR phase)

> **[RECOMMENDATION]** The database already contains foreign keys and enum/string fields to support all these dimensions. The dashboard UI simply needs to group and sum by these fields.
